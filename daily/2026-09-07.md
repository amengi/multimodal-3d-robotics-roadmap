### 2.2 分支与循环（10 分钟）

就地阅读：[Python 官方教程 §4.1–4.3](https://docs.python.org/3/tutorial/controlflow.html)，只读 if、for、range 的例子，5 分钟。

```python
for x, y in points:
    if x > 0:
        print("right", x, y)
    else:
        print("on or left of y-axis", x, y)

i = 0
while i < len(points):
    print(i, points[i])
    i += 1
```

`x, y` 将一对坐标拆开；缩进决定代码属于哪个分支或循环。`for` 逐个访问对象，`while` 在条件为真时继续执行。删掉 `i += 1` 会使这里的循环无法终止；理解原因即可，不要实际运行无限循环。`=` 是赋值，`==` 是比较。练习：只输出 y 大于 0 的点，并手写循环求所有 x 的和。

### 2.3 动手写 point_stats.py（25 分钟）

今天所有点都位于同一 world 坐标系，单位为米。质心是坐标均值：`cx = sum(x)/n`、`cy = sum(y)/n`；轴对齐包围盒是 `((xmin,ymin),(xmax,ymax))`；离原点最近的点使 `x*x+y*y` 最小。距离平方单位为平方米。并列最近时保留输入中第一个。

先对四个角点手算，再把以下代码保存到 `experiments/Day003/point_stats.py`。先尝试自己实现，卡住再对照：

```python
points = [(0, 0), (2, 0), (2, 2), (0, 2)]
if not points:
    raise ValueError("points must not be empty")

sx = sy = 0
xmin = xmax = points[0][0]
ymin = ymax = points[0][1]
nearest = points[0]
best_d2 = nearest[0] ** 2 + nearest[1] ** 2
for x, y in points:
    sx += x
    sy += y
    xmin = min(xmin, x)
    xmax = max(xmax, x)
    ymin = min(ymin, y)
    ymax = max(ymax, y)
    d2 = x * x + y * y
    if d2 < best_d2:
        nearest = (x, y)
        best_d2 = d2

centroid = (sx / len(points), sy / len(points))
bbox = ((xmin, ymin), (xmax, ymax))
print("centroid (m):", centroid)
print("bbox (m):", bbox)
print("nearest to origin (m):", nearest)
assert centroid == (1.0, 1.0)
assert bbox == ((0, 0), (2, 2))
assert nearest == (0, 0)
```

运行 `python experiments/Day003/point_stats.py`。预期质心 `(1.0, 1.0)`、包围盒 `((0, 0), (2, 2))`、最近点 `(0, 0)`。三个断言仅用于当前四角点样例。改变数据时，先手算并更新断言，不能直接沿用答案。

再做两个边界案例：单点 `[(3, -2)]` 的质心和最近点都是 `(3, -2)`，包围盒两角相同；空列表应报清晰错误，而不是进入除以零。扩展练习：输入 `[(-2, 0), (2, 0)]`，解释为什么保留 `(-2, 0)`。今天假设每个点都是两个有限数值，明天再把程序改为函数并系统验证非法输入。

## 3. 数据可视化：配对关系与边缘分布（40 分钟）

设 X、E 是独立标准高斯随机变量，构造 `Y = 0.8*X + 0.6*E`。X、Y 均无量纲，理论方差均为 1，相关系数为 0.8；有限样本的实测相关通常不会恰好等于 0.8。它们是同一批样本的两路模拟特征，不是真实医学观测。

将以下代码保存为 `experiments/Day003/visualize_pairs.py`，按“生成数据→检查→绘图→保存”逐段运行。`rng` 是随机数生成器，固定种子便于同一环境下重跑。

```python
from pathlib import Path
import numpy as np
import matplotlib
matplotlib.use("Agg")  # 保存图片，不依赖弹窗
import matplotlib.pyplot as plt

rng = np.random.default_rng(3)
x = rng.normal(size=1000)
e = rng.normal(size=1000)
y = 0.8 * x + 0.6 * e
assert x.shape == y.shape == (1000,)
assert np.isfinite(x).all() and np.isfinite(y).all()
assert not np.array_equal(x, y)

fig, axes = plt.subplots(1, 3, figsize=(12, 3.6))
axes[0].scatter(x, y, s=8, alpha=0.3)
axes[0].set(xlabel="X (unitless)", ylabel="Y (unitless)", title="Paired samples")
axes[1].hist(x, bins=30, alpha=0.5, label="X")
axes[1].hist(y, bins=30, alpha=0.5, label="Y")
axes[1].set(xlabel="Value (unitless)", ylabel="Count", title="Marginals")
axes[1].legend()
h = axes[2].hist2d(x, y, bins=30)
axes[2].set(xlabel="X (unitless)", ylabel="Y (unitless)", title="Joint histogram")
fig.colorbar(h[3], ax=axes[2], label="Count")
fig.tight_layout()
out = Path(__file__).resolve().parent
fig.savefig(out / "paired_views.png", dpi=150)
plt.close(fig)
print("seed=3, n=1000, rho_target=0.8")
print("sample correlation:", np.corrcoef(x, y)[0, 1])
print("versions:", np.__version__, matplotlib.__version__)
```

运行 `python experiments/Day003/visualize_pairs.py`，在脚本所在目录打开 `paired_views.png`。

就地参考：[Matplotlib hist2d 官方文档](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.hist2d.html)，只看 `bins`、`density` 与返回值，5 分钟。这里默认画每格计数；它不是直接计算出的互信息。

读图任务：散点图保留每个样本的 X/Y 配对；边缘直方图分别统计取值频数，不能单独说明配对关系；联合直方图用颜色汇总同时落入两个区间的样本数。将这三句话改写为你自己的解释。

接着只改一个因素：在画图前加入 `y = rng.permutation(y)`，重新运行。先将原图改名为 `paired_views_original.png` 以保留对照。解释为什么 Y 的边缘直方图不变，而散点形态、联合直方图和实测相关会变化。随机打乱后的相关通常接近 0，不保证恰好为 0。零相关一般不等于独立，今天不要把相关系数当成互信息。
