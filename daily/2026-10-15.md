## 概念一：针孔投影的雅可比

### 1. 从函数到矩阵

标量函数 `y=f(x)` 的导数是一个数；向量函数

```text
f: R^m -> R^n
x = [x1,...,xm]^T
y = [f1(x),...,fn(x)]^T
```

的雅可比把每个输出对每个输入的偏导排成矩阵：

```text
        [ df1/dx1 ... df1/dxm ]
J(x) = [   ...          ...   ]   shape (n,m)
        [ dfn/dx1 ... dfn/dxm ]
```

- **行**对应输出分量。
- **列**对应输入分量。
- 若输出单位是 pixel、输入单位是 m，元素单位就是 pixel/m。
- 局部线性近似是 `f(x+delta) ≈ f(x)+J(x)delta`，shape 为 `(n,m)@(m,)=(n,)`。

参考：[SciPy `differentiate.jacobian`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.differentiate.jacobian.html)只看多输出例子的 `df.shape==(4,3)`，4 分钟；看完能从输入/输出维数判断矩阵方向。

常见错误是把雅可比转置为 `(m,n)`。最快检查方法不是背布局，而是检查 `J delta_x` 是否得到输出增量。

### 2. 坐标系和针孔公式

本课只处理已经在相机坐标系中的点：

```text
p_c = [X,Y,Z]^T, shape (3,), unit m, Z>0
q   = [u,v]^T,   shape (2,), unit pixel
```

无 skew、无畸变时：

```text
u = fx * X/Z + cx
v = fy * Y/Z + cy
```

`fx,fy,cx,cy` 的数值单位记作 pixel。`X/Z`、`Y/Z` 是无量纲归一化坐标。这里没有世界到相机的 `R,t`，也没有径向/切向畸变；若真实任务含这些项，必须把链式法则继续展开。

参考：[OpenCV calib3d](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)只看 camera coordinates 到 normalized/image coordinates 的公式与相机矩阵，8 分钟；看完能区分 `p_w`、`p_c` 和像素点。

### 3. 逐项推导

对 `u`：

```text
du/dX = fx/Z
du/dY = 0
du/dZ = -fx*X/Z^2
```

对 `v`：

```text
dv/dX = 0
dv/dY = fy/Z
dv/dZ = -fy*Y/Z^2
```

所以：

```text
J = d[u,v]/d[X,Y,Z]
  = [[fx/Z,   0, -fx*X/Z^2],
     [  0, fy/Z, -fy*Y/Z^2]]   pixel/m
```

注意 `Z` 列同时影响 `u,v`。深度越接近 0，`1/Z` 和 `1/Z²` 越大，投影对三维扰动越敏感；这不是“近处一定估计更准”，而是小深度误差可能造成更大像素变化。

### 4. 最小手算

代入：

```text
p_c = [0.4,-0.2,2.0] m
fx=800 px, fy=820 px, cx=640 px, cy=360 px
```

投影：

```text
u = 800*0.4/2 + 640 = 800 px
v = 820*(-0.2)/2 + 360 = 278 px
```

雅可比：

```text
J = [[800/2, 0, -800*0.4/4],
     [0, 820/2, -820*(-0.2)/4]]
  = [[400, 0, -80],
     [0, 410, 41]] pixel/m
```

若 `delta_p=[0.001,0,0] m`，一阶预测为 `delta_q=J delta_p=[0.4,0] pixel`。若一次把 1 mm 当成 1 m，像素预测会错 1000 倍。

### 5. 雅可比不是全局线性模型

`f(x+delta)≈f(x)+Jdelta` 只在当前点附近成立。以下情况要重新线性化或换模型：

- `delta` 很大；
- `Z` 接近 0 或跨过相机平面；
- 忽略了明显镜头畸变；
- 输入其实在世界坐标系，却直接代入相机公式；
- 相机内参或单位写错。

参考：[OpenCV `projectPoints`](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)只看完整参数列表和 jacobian 说明，5 分钟；看完能指出本课少了哪些参数块。

## 概念二：用有限差分验证雅可比

### 1. 逐列中心差分

对第 `j` 个输入坐标，取单位向量 `e_j`：

```text
J[:,j] ≈ [f(x+h e_j)-f(x-h e_j)]/(2h)
```

每次只改变一个坐标，输出差是 shape `(2,)`，填入雅可比第 `j` 列。三列都做完才得到 `(2,3)`。

配套代码的核心可直接运行：

```python
import numpy as np

def project(p):
    X, Y, Z = p
    return np.array([800.0 * X / Z + 640.0,
                     820.0 * Y / Z + 360.0])

def numeric_jacobian(f, x, h=1e-5):
    y = f(x)
    J = np.empty((y.size, x.size))
    for j in range(x.size):
        delta = np.zeros_like(x)
        delta[j] = h
        J[:, j] = (f(x + delta) - f(x - delta)) / (2.0 * h)
    return J

p = np.array([0.4, -0.2, 2.0])
print(project(p))
print(numeric_jacobian(project, p))
```

预期输出接近：

```text
[800. 278.]
[[400.   0. -80.]
 [  0. 410.  41.]]
```

参考：[SciPy Jacobian](https://docs.scipy.org/doc/scipy/reference/generated/scipy.differentiate.jacobian.html)只看 `f(xi)->ndarray` 契约和 `df` shape，5 分钟；看完能检查自己的函数是否在差分期间改变输出 shape。

### 2. 为什么步长不是越小越好

- `h` 太大：高阶项没有消失，截断误差大。
- `h` 太小：两个极接近的浮点数相减，舍入误差被 `1/(2h)` 放大。

默认扫描 `h=10^-1,...,10^-11 m`，最佳离散扫描点是 `1e-5 m`。这个值依赖函数、尺度、dtype 和平台，不应写成普适常数。

成功判断要同时看：

1. 最大元素误差；
2. 各列单位和量级；
3. 多个步长是否形成先下降后上升的曲线；
4. 解析式与代码是否用同一坐标系和内参。

## 概念三：Pearson、CCA、HSIC 和高斯 MI

### 1. 先定义配对随机变量

多模态样本写成：

```text
X in R^Dx: 视图/模态 A
Y in R^Dy: 视图/模态 B
T in {0,1}: 下游任务标签
```

样本矩阵分别为 `(N,Dx)`、`(N,Dy)`。第 `i` 行必须对应同一对象、同一时间定义或明确的配准规则。若把 `Y` 的行打乱，边缘分布没变，但联合配对关系被破坏。

参考：[CMU MMML Lecture 4.1](https://multicomp.cs.cmu.edu/mmml-course/fall2023/schedule/)只看 “Alignment and grounding / Explicit alignment” 主题，5 分钟；看完能写出自己的 pairing key。

### 2. Pearson 只看一个线性方向

对标量 `X,Y`：

```text
rho = Cov(X,Y)/(sigma_X sigma_Y)
```

它无量纲、范围 `[-1,1]`。`rho≈0` 只说明没有明显的**线性**相关，不等于独立。

在 `X~Uniform(-2,2), Y=X²+noise` 中，正负 `X` 的线性趋势抵消，默认样本 Pearson 约 `0.029`，但从散点图明显能看出抛物线依赖。

### 3. CCA 寻找两个线性投影

线性 CCA 选择向量 `a,b`：

```text
maximize corr(a^T X, b^T Y)
```

令中心化协方差为：

```text
Cxx: (Dx,Dx)
Cyy: (Dy,Dy)
Cxy: (Dx,Dy)
```

白化后的交叉矩阵：

```text
M = Cxx^(-1/2) Cxy Cyy^(-1/2), shape (Dx,Dy)
```

对 `M=U diag(s) V^T` 做 SVD，奇异值 `s` 是典型相关。配套实现用一个很小的固定正则下限避免协方差数值奇异；没有在测试集调它。

参考：[NumPy `linalg.svd`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)只看 `full_matrices=False` 的 shape 规则，5 分钟；[scikit-learn CCA](https://scikit-learn.org/stable/modules/generated/sklearn.cross_decomposition.CCA.html)只看输入、输出与 `n_components`，5 分钟。看完能写出一维 CCA 等于 `|Pearson|`，也能说明 CCA 仍是线性方法。

退化与误区：

- 某一特征恒定时方差为 0，Pearson/白化无定义或病态。
- `N` 太小、维数太大时样本协方差奇异，典型相关可能虚高。
- 先在全数据上选维数/正则再报测试结果会泄漏。
- 高 CCA 可能来自设备、患者 ID 或时间戳，而不是任务信号。

### 4. HSIC 是核依赖统计量，不是 MI

用核矩阵 `K,L` 和中心化矩阵 `H=I-11^T/N`，本课报告有偏经验统计量：

```text
HSIC_b = trace(K H L H)/(N-1)^2
```

RBF 核把非线性相似性映射到高维特征空间，因此能发现 Pearson/线性 CCA 漏掉的抛物线依赖。本课用中位距离启发式设带宽。

参考：[Gretton & Györfi, JMLR](https://www.jmlr.org/beta/papers/v11/gretton10a.html)先看摘要与 PDF 中 HSIC 定义附近，不通读证明，10 分钟；看完必须能写出“核选择与有限样本标定影响统计量”。

重要边界：

- 数值没有 bit/nat 单位，不能和 MI 数值横向比较。
- 不同核、带宽、样本量的原始数值不可直接排名。
- 一次打乱只是失败对照，不是正式置换检验，不给 p 值。
- 本实现需要两个 `(N,N)` float64 核矩阵；`N=400` 时约 `2.44 MiB`，时间/内存为 `O(N²)`。

### 5. 联合高斯时的 MI 闭式

只有对**标量、非退化、联合高斯**的 `(X,Y)`，相关系数 `rho` 与 MI 才有闭式：

```text
I(X;Y) = -1/2 log2(1-rho^2)  bit/pair
```

当 `rho=0.8`：

```text
I = -0.5 log2(1-0.64)
  = -0.5 log2(0.36)
  = 0.736966 bit/pair
```

默认有限样本相关约 `0.765587`，代回公式得到 `0.636364 bit/pair`。它是带高斯结构假设的 plug-in 估计，不应称为一般真实 MI。

参考：[MIT 6.441 Lecture Notes](https://ocw.mit.edu/courses/6-441-information-theory-spring-2016/pages/lecture-notes/)只看 Chapter 2 的 MI 定义目录和 Chapter 17 的 Gaussian channels 目录，10 分钟；看完能区分 MI 定义与本课附加的联合高斯闭式假设。

不能把闭式套到 `Y=X²+noise`：Pearson 接近 0 会给近 0 的“高斯 MI”，但真实变量明显依赖。那不是证明 MI 为 0，而是模型假设错了。

5. 同时报任务 accuracy、Brier、NLL 和计算成本；检查点：干净融合优于稳定单模态，共享标识不应被写成任务价值。
