## 3. 主线：点线距离与 Gauss–Newton

### 3.1 数据合同、坐标系与单位

输入 `P.shape==(N,2)`，每行是 `[x_i,y_i]`，单位 m，坐标系为 synthetic world-xy。法线式直线：

```text
x cos(theta) + y sin(theta) - rho = 0
```

- 参数 `p=[theta,rho]`，shape `(2,)`；
- `theta` 为法向量与 x 轴夹角，单位 rad；
- `rho` 为原点沿法向量到直线的有符号距离，单位 m；
- 残差 `r_i=x_i cos(theta)+y_i sin(theta)-rho`，单位 m。

因为 `[cos(theta),sin(theta)]` 是单位法向量，内积给出法向投影，减 `rho` 后就是有符号正交距离。最小算例：点 `(2,3) m`、`theta=pi/2`、`rho=1 m`，得 `r=2 m`。

不用 `y-(mx+b)`，因为它只测 y 方向误差；法线式测正交距离，也能表示竖直线。

### 3.2 雅可比

```text
dr_i/dtheta = -x_i sin(theta) + y_i cos(theta)
dr_i/drho   = -1
J_i = [-x_i sin(theta) + y_i cos(theta), -1]
J.shape == (N,2)
```

第一列单位 m/rad，第二列 m/m。两列尺度可能不同，实际问题需要缩放或阻尼，不能忽略量纲。

### 3.3 GN 推导

局部一阶近似与目标：

```text
r(p+delta) ≈ r(p) + J delta
min_delta 0.5 * ||r + J delta||^2
```

对 `delta` 求导并令零：

```text
J.T(r + J delta) = 0
(J.T J) delta = -J.T r
```

| 对象 | shape | 含义 |
|---|---:|---|
| `r` | `(N,)` | N 个有符号距离 |
| `J` | `(N,2)` | 残差对两个参数的导数 |
| `J.T@J` | `(2,2)` | Hessian 的 GN 近似 |
| `-J.T@r` | `(2,)` | 线性系统右端 |
| `delta` | `(2,)` | 角度与距离增量 |

```python
residual = line_residuals(params, points_m)
jacobian = line_jacobian(params, points_m)
hessian_approx = jacobian.T @ jacobian + 1e-8 * np.eye(2)
gradient = jacobian.T @ residual
delta = np.linalg.solve(hessian_approx, -gradient)
params = params + delta
```

`1e-8 I` 是小数值阻尼，降低近奇异不稳定；它不等于完整 LM 的自适应信赖域。

### 3.4 数值雅可比检查

```text
J_num[:,j] ≈ (r(p+h e_j) - r(p-h e_j)) / (2h)
```

项目用 `h=1e-6`，要求 `max(abs(J_analytic-J_numeric)) < 1e-7`。`h` 太大时截断误差大；太小时浮点相消明显。数值检查必须独立扰动残差函数，不能复制解析导数逻辑“自证正确”。

就地参考：[SciPy least_squares](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html) 的 jac 参数，只看 2-point、3-point、callable，4 分钟；读完能解释为何检查应独立。

### 3.5 普通几何基线与失败

普通基线是 TLS/PCA：点集中心化后，取 `(2,2)` 散布矩阵最小特征值的特征向量作法向量。对今日无权点线平方距离，它是封闭解；GN 应到同一 RMSE。若 GN 对不上 TLS，不要用“非线性更高级”解释。

失败条件：

- 点重合或参数不可辨识，`J.T@J` 可能奇异；
- 初值太差，一阶局部近似不可靠；
- L2 对离群点敏感；今日小高斯噪声结果不能外推到重尾外点；
- `(theta,rho)` 与 `(theta+pi,-rho)` 表示同一条线。

## 4. 信息论/多模态：InfoNCE 与表示评测

### 4.1 随机变量、shape 与配对

- `X_img`：`image.shape==(B,D)`；
- `X_txt`：`text.shape==(B,D)`；
- `Y`：8 类语义标签，`labels.shape==(B,)`；
- `B=64,D=8`，每行 L2 归一化；
- 同一行是严格配对；同类不同行可能语义合理，却被对角线目标当负样本。

```text
S = Z_img @ Z_txt.T
S.shape == (B,B)
S_ij = dot(z_img_i,z_txt_j)
```

`S_ii` 是指定正样本，其余是当前 batch 负样本。

### 4.2 对称 InfoNCE

```text
p(i->j) = exp(S_ij/tau) / sum_k exp(S_ik/tau)
L_i2t = -mean_i log p(i->i)
L_sym = 0.5 * (L_i2t + L_t2i)
```

`tau>0` 是无量纲 temperature。2×2 手算：一行 `S/tau=[2,0]`，正配对概率约 `0.881`，NLL 约 `0.127 nat`。代码先减行/列最大值，避免指数溢出。

### 4.3 下界不是真实 MI

特定假设下常写批量诊断 `I_NCE=log(B)-loss`，转 bit 为 `(log(B)-loss)/log(2)`。它依赖 batch size、负样本、false negatives、temperature、表示、打分函数和有限样本。

不能写：

- “真实图像—文本 MI 等于 5.59 bit”；
- “InfoNCE 更小证明表示一定更好”；
- “高相似度证明文本导致图像内容”。

就地参考：[CPC](https://arxiv.org/abs/1807.03748) 2.3 节和下界表述，7 分钟；[VBMI](https://github.com/google-research/google-research/tree/master/vbmi) README 中多种界并列，3 分钟。读完能说“下界不是无偏真值”。

### 4.4 temperature、batch 与 false negatives

- `tau` 小：softmax 更尖；loss 可降，也可能更怕噪声。
- `B` 大：负样本增多，`log(B)` 与 loss 同时变；不能只跨 batch 比 loss。
- false negative：不同行表达同一语义，却被严格配对目标当负例。

同时报告 strict-pair top-1、semantic top-1、InfoNCE/batch bound、下游分类。失败例把同类 4 个样本的表示完全填平：语义类仍可找对，类内行号却不可辨。

### 4.5 判别、校准与不确定性分开

用 `normalize(image+text)` 做最近类中心分类，普通基线是 8 类均匀预测。

- accuracy：argmax 判别能力；
- NLL：`-mean(log p_y)`，nat/example；
- multiclass Brier：`mean(sum_k (p_k-onehot_k)^2)`；
- ECE(5 bins)：分箱后的准确率—置信度差距；依赖分箱，不是完美校准证明；
- 高预测熵不等于必错，低熵不保证正确。

类中心只用 train 拟合；temperature 只在 validation 按 NLL 选择，test 只评一次。不得用 test 调参。

就地参考：[Guo 等](https://proceedings.mlr.press/v70/guo17a.html)只读摘要、ECE/reliability diagram、temperature scaling，6 分钟；读完能解释“accuracy 不变而 NLL/ECE 可变”。

参考（先答后看）：[第 4.5 节](#45-判别校准与不确定性分开)与 [Guo 等](https://proceedings.mlr.press/v70/guo17a.html)，5 分钟。不要把生成图像逼真当诊断可靠，不要把高相似度当临床因果。

<details>
<summary>折叠答案（必须先独立作答）</summary>

1. 单位法向量与点内积是法向投影，减 `rho` 得有符号正交距离。`theta` 为 rad，`rho/r_i` 为 m。
2. 对 `0.5||r+Jdelta||^2` 求导得 `J.T(r+Jdelta)=0`，即 `(J.TJ)delta=-J.Tr`。`J:(N,2)`、`JTJ:(2,2)`、`delta:(2,)`。
3. `h` 大时截断误差大，小时浮点相消明显。若数值检查复制解析逻辑，两者相同不是独立证据。
4. `(64,8)@(8,64)=(64,64)`，第 `i` 行 `j=i` 是正例。
5. 依赖 batch size、负样本/false negatives、temperature、打分函数、表示和有限样本；是下界诊断，不是真 MI。
6. 类内填平后候选语义等价；任取一个都语义正确，但对角线要求唯一行号，严格配对不可辨。
7. 正 temperature 缩放不改 argmax，所以 accuracy 不变；它改变概率尖锐度，所以 NLL/Brier/ECE 变。test 选参会泄漏。
8. 动手题无预设“0.50 必然更差”；必须引用实测 loss 与两种 top-1，并声明不是 MI 真值。
9. 医学迁移按患者，最好再按机构/时间划分；比较稳定单模态或简单 late fusion；报 AUROC/AUPRC 等任务指标与 NLL/Brier/ECE；检查身份、设备、报告模板泄漏。
