## 概念一：SVD 把任意矩阵放到最合适的输入/输出基

### 定义、shape 与几何直觉

对实矩阵 `A:(m,n)`，令 `k=min(m,n)`。compact SVD 是：

```text
A = U Sigma V^T
U:(m,k), Sigma:(k,k), V^T:(k,n)
```

- `V` 的列 `v_i` 是输入空间中的正交单位方向；
- `A v_i = sigma_i u_i`，先沿 `v_i` 取分量，再乘非负伸缩 `sigma_i`；
- `U` 的列 `u_i` 是输出空间中的正交单位方向；
- `sigma_1>=...>=sigma_k>=0`，奇异值无单位规则取决于 `A` 的输入输出单位；
- 非零奇异值数量等于 rank。

若 `A` 把单位为 m 的坐标映到单位为 pixel 的观测，那么 `A` 的元素和奇异值单位是 pixel/m；`U,V` 是归一化方向，无量纲。今天的图像矩阵把“行方向系数”映成灰度列剖面，元素和奇异值按归一化灰度计算，不给它物理长度单位。

NumPy 在 `full_matrices=False` 时直接返回 `U,s,Vh`，其中 `s` 是一维数组，不是矩阵；重建可写为：

```python
(U * s) @ Vh
```

这里广播把 `U` 的第 `i` 列乘 `s[i]`。参考：[NumPy `svd`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)只看 Parameters/Returns 和 `full_matrices=False`，5 分钟；看完能避免把 `Vh` 再错误转置。

### 与 `A^T A` 的联系

由 `A=U Sigma V^T`：

```text
A^T A = V Sigma^T Sigma V^T
```

所以 `v_i` 是 `A^T A` 的特征向量，对应特征值 `sigma_i^2`。类似地，`u_i` 是 `AA^T` 的特征向量。SVD 比一般特征分解适用范围更广：`A` 可以是非方阵、非对称矩阵。

### 手算例：rank-1 矩阵的 SVD

取 MIT 讲义中的矩阵：

```text
A = [[4,3],
     [8,6]]
```

第二行是第一行两倍，rank 为 1。计算：

```text
A^T A = [[80,60],
         [60,45]]
```

其行列式为 0，所以一个特征值是 0；迹为 125，所以另一个特征值是 125。奇异值：

```text
sigma_1=sqrt(125)=5sqrt(5), sigma_2=0
```

可取：

```text
v_1=[4/5,3/5]^T
u_1=[1/sqrt(5),2/sqrt(5)]^T
```

验证：

```text
A v_1 = [5,10]^T = 5sqrt(5) u_1
```

补齐与它们垂直的单位向量即可得到方阵 `U,V`。向量整体反号仍是同一 SVD 方向；判断正确应看重建、正交与 `Av_i=sigma_i u_i`，不能逐元素硬比符号。

参考：[MIT 18.06 SVD](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/pages/positive-definite-matrices-and-applications/singular-value-decomposition/)只看 Overview、lecture summary 第一个 rank-1 例子，12 分钟；看完能独立完成上面四行验算。

## 概念二：截断 SVD、图像压缩与普通误差基线

### 从 full SVD 到 rank-`r`

把 SVD 展开成 rank-1 外积之和：

```text
A = sum_i sigma_i u_i v_i^T
A_r = sum_{i=1}^r sigma_i u_i v_i^T
```

保留最大的 `r` 个奇异值就是截断 SVD。Eckart–Young 结论告诉我们，在所有 rank 不超过 `r` 的矩阵中，`A_r` 使 2-范数和 Frobenius 范数误差最小：

```text
||A-A_r||_2 = sigma_{r+1}
||A-A_r||_F^2 = sum_{i>r} sigma_i^2
```

今天仍要报告普通指标，不能只看奇异值或 MDL：

```text
MSE  = mean((A-A_r)^2)            # intensity^2
RMSE = sqrt(MSE)                   # intensity
PSNR = 10 log10(1/MSE)             # dB, data_range=1
```

rank 0 全零图是最简单基线；full rank 是浮点重建上界。rank 4 和 rank 16 是中间候选。图像显示固定 `cmap='gray',vmin=0,vmax=1`，否则每张图自动拉伸会掩盖真实误差。

参考：[MIT 图像压缩课](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/pages/positive-definite-matrices-and-applications/change-of-basis-image-compression/)只看 Overview 和 lecture summary 的压缩动机，6 分钟；[Matplotlib `imshow`](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.imshow.html)只看 `(M,N)` 灰度输入与 `cmap/vmin/vmax`，4 分钟；看完能用统一显示尺度比较重建。

### 参数量只是代理，不是文件大小

若直接存 `U_r,s_r,V_r^T`，标量数是：

```text
r*m + r + r*n = r(m+n+1)
```

本图 `m=64,n=96`：rank 4 有 `4*(64+96+1)=644` 个标量，rank 16 有 2576 个。真实文件大小还取决于数据类型、量化、熵编码、文件头、是否利用正交结构；因此课件只称它“参数量代理”。

## 概念三：条件数衡量逆问题对相对扰动的最坏敏感度

### 2-范数条件数

对满秩方阵：

```text
kappa_2(A)=||A||_2 ||A^-1||_2=sigma_max/sigma_min
```

- `kappa≈1`：各方向缩放接近，逆问题相对稳定；
- `kappa` 很大：某方向被压得很小，求逆时又除以很小的 `sigma`，噪声可能被放大；
- `sigma_min=0`：矩阵奇异，`kappa=inf`，普通逆不存在。

对 `Ax=b` 的小扰动，在合适条件下有一阶上界直觉：

```text
relative_error(x) <= kappa(A) * relative_error(b)
```

这是最坏方向的上界，不是每次误差都恰好乘 `kappa`，也不是概率保证。

参考：[NumPy `cond`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.cond.html)只看 `p=None/2/-2`、返回值和定义，5 分钟；看完能解释为什么 2-范数条件数由最大/最小奇异值决定。

### 截断伪逆：稳定性与偏差的交换

SVD 伪逆形式：

```text
A^+ = V Sigma^+ U^T
```

`Sigma^+` 对保留的非零奇异值取倒数。`pinv` 的 cutoff 会把相对最大奇异值过小的方向设为零：

- cutoff 小：保留更多方向，残差更小，但可能放大噪声；
- cutoff 大：丢弃不稳定方向，噪声放大降低，但解产生偏差；
- cutoff 不能看测试答案后随意调；应按噪声尺度、验证集或先验规则确定。

参考：[NumPy `pinv`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.pinv.html)只看 SVD 定义、`rcond/rtol` 和 Moore–Penrose 检查，6 分钟；看完能说出 cutoff 改变了哪些奇异方向。

## 概念四：MDL 不是“参数最少”四个字

### 从 NLL 到二段编码直觉

若概率模型给正确标签概率 `p(y_i|x_i)`，数据部分理想码长与 NLL 相连：

```text
NLL_nat = -sum_i ln p(y_i|x_i)
L_data_bit = -sum_i log2 p(y_i|x_i) = NLL_nat/ln 2
```

简单的二段码直觉是：

```text
L_total = L_model + L_data_given_model
```

只比较参数量会忽略拟合；只比较训练 NLL 又会偏向复杂模型。MDL 思想用一套明确编码/通用分布同时处理复杂度与拟合。严谨 MDL 远不止“参数数×固定 bit”：参数精度、模型类、通用码、NML 是否存在、数据顺序等都会改变定义。

今天的图像代理明确固定：每个模型标量 16 bit；残差采用固定 `sigma=0.03` 的零均值高斯密度，并用 `1/255` 灰度 bin 近似概率。融合模型代理固定：每参数 8 bit，加标签 NLL bit。这两个代理的编码约定不同，**不得跨表直接比较总 bit**。

参考：[Minimum Description Length Revisited](https://arxiv.org/abs/1908.08484)只读摘要、Introduction 前两段以及 two-part/universal code 的定位，10 分钟；看完能解释为什么本课计算只是代理，不能标成 exact MDL。

### accuracy、NLL 与校准必须区分

本课两个合成分类器 accuracy 都是 1，但融合模型给正确标签更高概率，所以 NLL 更低。accuracy 只看阈值后的对错；NLL 还看概率分配是否把质量给正确标签。然而低 NLL 并不自动证明校准：校准需要独立验证/测试设计、可靠性图或 Brier/ECE 等证据，校准参数只能在验证集拟合。

本例不涉及真实缺失模态；若迁移到非完备医学多模态，必须另外定义模态 `X`、标签 `Y`、缺失指示 `R`，区分训练/测试/现实缺失，讨论 MCAR/MAR/MNAR，并按模态子集报告样本量、任务性能和校准。研究教学不作临床诊断建议。

| 方法 | 相对残差 | 相对解误差 | 解释 |
|---|---:|---:|---|
| direct / `rcond=1e-12` | `0` | `0.007071` | 完全拟合 noisy `b`，也保留噪声 |
| `pinv rcond=1e-3` | `0.000101` | `0.707107` | 丢弃小奇异方向，稳定但偏差很大 |

不能只看残差选 cutoff：直接解残差为零，却不等于恢复了无噪声真值。参考：[NumPy `cond`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.cond.html)核对条件数；[NumPy `pinv`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.pinv.html)核对 cutoff 语义。

### 实践 C：参数量、NLL 与描述长度代理

先比较图像 rank 扫描：rank 增大时 RMSE 单调下降，full rank 的重建几乎完美；但在本课固定代理下，总长度由 rank 1 的 `63.924 kbit` 降到 rank 4 的 `41.444 kbit`，随后 rank 8 回升到 `48.347 kbit`。这只支持“在当前数据和当前编码约定下 rank 4 最小”。

再看固定合成预测概率：

| 模型 | 参数量 | accuracy | NLL (nat/example) | `L_model` (bit) | 总代理 (bit) |
|---|---:|---:|---:|---:|---:|
| 稳定单模态 | 4 | 1.000 | 0.339281 | 32 | 423.583 |
| 双模态融合 | 18 | 1.000 | 0.214543 | 144 | 391.616 |

这里参数少的模型不是总代理最小，NLL 低的模型也不是“无需复杂度代价”。若把样本数减少、参数位宽增加或换一种通用码，选择可能翻转。参考：[MDL Revisited](https://arxiv.org/abs/1908.08484)核对 MDL 不是简单参数惩罚；不要把这张合成表解释成多模态的普遍优势。

## 常见错误与报错处理

1. **把 `Vh` 当 `V`**：NumPy 返回的是 `V^T`/共轭转置，重建直接用 `@ Vh`。
2. **误读 compact shape**：`k=min(m,n)`；本图是 `(64,96)`，所以 `U:(64,64)`、`Vh:(64,96)`。
3. **手写 `diag(s)` 后 shape 错**：可用 `(U*s)@Vh`；广播按列缩放 `U`。
4. **按元素比较奇异向量**：每对 `u_i,v_i` 可同时反号；检查重建与子空间。
5. **认为 rank 越小一定更好**：低 rank 省参数但可能丢边缘/纹理；必须报 RMSE、PSNR、图和任务指标。
6. **把 PSNR 当临床可靠性**：像素指标不证明诊断、分割、校准或外部鲁棒性。
7. **把大条件数说成一定失败**：它是最坏相对敏感度；还要看实际扰动方向与尺度。
8. **只按残差调 `rcond`**：更小残差可能只是把噪声拟合进解；cutoff 必须预先规定或用验证证据。
9. **把代理称 exact MDL**：今天的每参数 bit 和残差分布都是人为声明的课堂编码规则。
10. **accuracy 相同就认为概率模型相同**：继续比较 NLL/Brier/校准；accuracy 丢掉概率幅度。
11. **NaN 导致 SVD 不收敛**：先检查 `np.isfinite(A).all()`；脚本会在 SVD 前拒绝非有限值。
12. **Matplotlib 缓存不可写**：设置 `MPLCONFIGDIR=/tmp/day027-mpl`。
