## 概念一：特征值和特征向量

### 线性变换寻找“不转向”的方向

对方阵 `A:(2,2)`，非零向量 `v:(2,)` 若满足

```text
A v = lambda v
```

则 `v` 是右特征向量，`lambda` 是对应特征值。一般向量经 `A` 后会转向；特征向量只被缩放：

- `lambda>1`：沿该方向拉长；
- `0<lambda<1`：沿该方向缩短；
- `lambda<0`：反向并缩放；
- `lambda=0`：该方向被压到零，说明 `A` 有非平凡零空间。

把式子移项：

```text
(A-lambda I)v=0
```

要有 `v!=0`，矩阵 `A-lambda I` 必须奇异，因此：

```text
det(A-lambda I)=0
```

这叫特征方程。今天理解 2×2 手算即可；代码不自己展开高次多项式，而调用对称矩阵专用求解器。

参考：[MIT 18.06 Lecture 21](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/lecture-21-eigenvalues-and-eigenvectors/)只看“`Ax` 与 `x` 同方向”的定义和第一个 2×2 例子，12 分钟；看完应能从几何与方程两种语言解释同一件事。

### 手算例：从 `Av=lambda v` 到主方向

取三个点，单位 m：

```text
X = [[0,2],
     [1,1],
     [2,0]]
mean = [1,1]
Xc = [[-1, 1],
      [ 0, 0],
      [ 1,-1]]
```

样本协方差用 `N-1=2`：

```text
C = Xc^T Xc/(N-1)
  = [[ 1,-1],
     [-1, 1]] m²
```

特征方程：

```text
det(C-lambda I)
=(1-lambda)^2-1
=lambda(lambda-2)=0
```

所以 `lambda1=2 m²`、`lambda2=0 m²`。可选单位特征向量：

```text
v1=[1,-1]/sqrt(2)   # 点云延伸方向
v2=[1, 1]/sqrt(2)   # 没有样本方差的垂直方向
```

检查：`C v1=2 v1`，`C v2=0 v2`。若软件返回 `-v1`，仍是同一条轴，因为 `C(-v1)=lambda(-v1)`。比较方向用：

```text
angle = arccos(|v_est^T v_true|)
```

绝对值消除正负号歧义。

### 为什么协方差用 `eigh` 而不是随便用 `eig`

实数样本协方差满足：

```text
C^T=C
z^T C z >= 0
```

它是实对称半正定矩阵，因此：

- 特征值为实数且理论上非负；
- 可选一组相互正交的单位特征向量；
- `V^T V=I`，可用 `V` 在原坐标和 PCA 坐标间旋转；
- `np.linalg.eigh` 返回升序特征值，特征向量在返回矩阵的列中，本课必须反转排序。

浮点计算可能产生 `-1e-15` 一类极小负值，应结合尺度与容差判断；不能把明显负特征值静默截为 0。参考：[NumPy `eigh`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eigh.html)只看输入为 Hermitian/real symmetric、返回顺序和 `a @ v[:,i] = w[i]v[:,i]`，5 分钟；看完能写三条断言。

## 概念二：协方差与 PCA

### 输入、shape、单位和坐标系

本课约定：

| 对象 | shape | 单位/坐标系 | 含义 |
|---|---:|---|---|
| `X` | `(N,2)` | m，二维世界坐标 | 每行一个点 `(x,y)` |
| `mu` | `(2,)` | m，同一世界坐标 | 样本均值 |
| `Xc=X-mu` | `(N,2)` | m | 中心化点 |
| `C=Xc.T@Xc/(N-1)` | `(2,2)` | m² | 无偏样本协方差 |
| `lambda` | `(2,)` | m² | 各主轴上的样本方差 |
| `V` | `(2,2)` | 无量纲 | 列为单位特征向量 |
| `Z=Xc@V` | `(N,2)` | m | PCA 坐标/得分 |
| `Xhat=Zhat@V.T+mu` | `(N,2)` | m | 重建点 |

如果把 `X:(N,2)` 直接传给默认 `np.cov(X)`，默认 `rowvar=True` 会把每行当变量，得到错误的 `(N,N)`。本课手写公式避免歧义；若调用 `np.cov`，必须写 `rowvar=False, ddof=1`。

参考：[NumPy `cov`](https://numpy.org/doc/stable/reference/generated/numpy.cov.html)只看输入布局、`rowvar`、`ddof` 和第一个反相关例子，6 分钟；看完能解释为什么手算例得到 `[[1,-1],[-1,1]]`。

### 最大投影方差推导

找一个单位方向 `u:(2,)`，将中心化点投影成 `z=Xc u`。投影的样本方差是：

```text
Var(z) = z^T z/(N-1)
       = u^T Xc^T Xc u/(N-1)
       = u^T C u
```

若不限制长度，把 `u` 放大就能无意义地放大方差，所以加 `u^T u=1`。拉格朗日函数：

```text
L(u,lambda)=u^T C u-lambda(u^T u-1)
```

对 `u` 求梯度并置零：

```text
2Cu-2lambda u=0
Cu=lambda u
```

因此驻点就是特征向量；在这些方向上 `u^T C u=lambda`，取最大特征值对应的特征向量就是第一主成分。解释方差比：

```text
EVR_k=lambda_k/sum_j lambda_j
```

今天 PC1 EVR 为 `0.992008`，说明它保留约 99.2% 总样本方差；这只谈二阶几何能量，不等于保留 99.2% 语义、任务信息或因果因素。

## 概念三：率—失真不是只报一个压缩比

### 四个对象必须一起声明

率—失真问题至少要声明：

1. 随机源 `X`：要压缩的对象及其分布；今天是一条二维点，单位 m。
2. 重建 `Xhat`：解码器输出，shape 仍为 `(2,)`。
3. 码率 `R`：今天是固定长度预算 bit/point。
4. 失真 `d(x,xhat)` 与允许平均失真 `D`：今天几何主指标为平方欧氏距离 m²/point。

经典定义可写成：

```text
R(D) = min_{p(xhat|x): E[d(X,Xhat)]<=D} I(X;Xhat)
```

它问：在平均失真不超过 `D` 时，理论上至少需要多少信息率。失真函数一改，`R(D)` 问题也改了。今天的脚本只扫描两个手工设计的标量量化策略，报告名义固定率与经验失真；没有优化所有 `p(xhat|x)`，所以不能把曲线标成理论 `R(D)`。

参考：[MIT 6.441 Chapter 23](https://ocw.mit.edu/courses/6-441-information-theory-spring-2016/resources/mit6_441s16_chapter_23/)只看 23.1 scalar quantization、信息论向量量化的定义和第一幅示意，10–15 分钟；看完能写出 `X,Xhat,R,d,D` 并说出本实验少了哪一步理论优化。

### 为什么“像素好看”不等于“任务可靠”

在研究教学的医学图像压缩情境中，至少区分：

- 像素失真：MSE、PSNR，容易计算，但可能平均掉小病灶或边界；
- 结构失真：SSIM 一类局部结构指标，仍不直接等于诊断效用；
- 任务失真：分类错误、分割 Dice 损失、测量偏差等，依赖已定义任务和独立验证。

本课把标签放在低方差方向，故高方差优先编码获得更低几何 RMSE，却接近随机任务 accuracy；任务感知编码牺牲一些几何 RMSE，给次轴 1 bit 后保住符号。它只证明“这个合成例子中目标冲突”，不证明真实医学压缩应照搬 1 bit 分配，也不作临床建议。

参考：[scikit-image metrics](https://scikit-image.org/docs/stable/api/skimage.metrics.html)只看 `mean_squared_error`、`peak_signal_noise_ratio`、`structural_similarity` 的输入和 `data_range`，5 分钟；看完能列出三个指标各自没有证明什么。

代码里量化范围只在校准集拟合；超范围评估值会 clipping。若把所有数据一起拟合范围，指标会含有评估信息泄漏。这里的“泄漏”是工程评估问题，不是差分隐私或 MI 证明。

参考：[`README` 如何读两张图](../materials/day026/README.md#如何读两张图)先看 3 分钟，再对照 [MIT 6.441 Chapter 23](https://ocw.mit.edu/courses/6-441-information-theory-spring-2016/resources/mit6_441s16_chapter_23/) 的失真定义；看完能指出本课曲线为何是 empirical codec scan。

### 跨线失败：特征值几乎相等时没有稳定主方向

脚本另生成 80 个 `N=40` 的近各向同性样本。每次 `eigh` 都会给出一个主特征向量，但第一、第二特征值接近时，样本噪声足以大幅旋转它。当前证据：

```text

angle_range_deg ≈ 166.894
median_eigengap_ratio ≈ 0.341
```

注意：无向角在 `[0,180)`，所以范围只是易懂的失败信号，不是最严谨的圆统计区间。核心判断来自“小 eigengap + 重采样方向不稳定”。修复路线：增加样本、bootstrap 方向、报告 eigengap/区间；不能仅靠固定特征向量符号制造稳定假象。

## 常见错误与报错处理

1. **把 `(N,2)` 当 `(2,N)`**：先打印 shape；每行一个点时手写 `Xc.T@Xc/(N-1)`，或 `np.cov(X,rowvar=False,ddof=1)`。
2. **忘记中心化**：直接算 `X.T@X` 会把坐标原点位置混入“方向”。PCA 的协方差围绕样本均值。
3. **取了最小特征值对应列**：`eigh` 返回升序，本课显式 `argsort(...)[::-1]`。
4. **把 `V[0]` 当第一特征向量**：NumPy 的特征向量在列里，应取 `V[:,0]`。
5. **箭头反向就判错**：`v` 和 `-v` 等价，比较 `abs(dot)`。
6. **把 EVR 当语义保真率**：EVR 只度量样本方差，不是 MI、任务 accuracy 或因果解释。
7. **只看 RMSE**：至少同时报任务指标和失败案例；真实医学结论需要独立数据与适当专业验证。
8. **把经验曲线叫 Shannon `R(D)`**：本课没有对所有条件分布优化，只是固定量化器扫描。
9. **校准参数看了评估集**：PCA、范围和阈值只能在校准集确定；评估集只用于最终报告。
10. **`ModuleNotFoundError`**：激活 `/tmp/day026-venv` 并按 requirements 安装；不要把依赖目录提交。
11. **Matplotlib 缓存不可写**：设置 `MPLCONFIGDIR=/tmp/day026-mpl`。
