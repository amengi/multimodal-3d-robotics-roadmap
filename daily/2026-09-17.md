## 概念一：“能打开”不等于“数据正确”

### 1. 数据契约的六个部件

| 部件 | 本课例子 | 不写会怎样 |
|---|---|---|
| 语义 | `K_px` 是相机内参 | 把普通 3×3 矩阵当内参 |
| shape | 点云 `(N,3)` | 把 `(3,N)` 读成 N 个点 |
| dtype | 点云 `float64` | 整数截断或低精度误差 |
| 单位 | 平移 `m`，偏航角 `rad`，内参 `px` | 米/毫米、度/弧度混用 |
| 坐标系/约定 | `T_world_camera` | 反向使用位姿 |
| 版本 | `schema_version=1` | 新程序静默误读旧文件 |

位姿 `T_world_camera` 表示：输入相机坐标系中的点 `p_camera`，输出世界坐标系中的点 `p_world`。这不能与 `T_camera_world` 混用。

### 2. 相机内参的 shape 与单位

```text
K = [[fx,  0, cx],
     [ 0, fy, cy],
     [ 0,  0,  1]]    shape=(3,3), fx/fy/cx/cy 单位都是像素 px
```

针孔相机投影：

\[
u=f_x X/Z+c_x, \qquad v=f_y Y/Z+c_y.
\]

`(X,Y,Z)` 是相机光学坐标系中的三维点，单位可以是 m，但三个分量必须同单位；`(u,v)` 是像素坐标。因为 `X/Z` 无量纲，乘 `f_x` 后得到 px。

**就地参考**：打开[NumPy I/O how-to](https://numpy.org/doc/stable/user/how-to-io.html)，只比较 text/binary 和 `load/save`，8 分钟。看完合上网页，用自己的话说出“为什么 NPY 适合精确保留 dtype/shape，CSV 适合查看表格”。

### 3. 四种格式的职责

| 格式 | 今日内容 | 优点 | 失败风险 |
|---|---|---|---|
| JSON | 嵌套配置和 schema | 人可读、有键名 | 默认可写 `NaN`；键缺失不一定报错 |
| CSV | 每帧一行的位姿 | 表格工具可读 | 小数位丢精度；列顺序/单位易混 |
| NPY | `(N,3)` 点云 | 保留 shape/dtype，往返无损 | 不适合手工查看；不信任数据应禁用 pickle |
| PNG | RGB 标定图 | 广泛可视化 | 解码可得 RGB 或 RGBA；不保存米制几何语义 |

**就地参考**：[Python JSON Basic Usage](https://docs.python.org/3/library/json.html#basic-usage)，只看 `dump/load` 和 `allow_nan`，8 分钟；[Python CSV](https://docs.python.org/3/library/csv.html#module-contents)，只看 `reader/writer/DictReader`，8 分钟。看完能为新表写含单位的列名。

### 4. 往返误差与文本量化

原数组 `P` 写出后再读回为 `P_hat`，用：

\[
e_\infty=\max_{i,j}|P_{ij}-\hat P_{ij}| \quad [\mathrm{m}].
\]

对保留 `d` 位小数的四舍五入 CSV，单个数理想最大量化误差是：

\[
|e|\leq \tfrac12 10^{-d}\;\mathrm{m}.
\]

当 `d=3`时是 `0.0005 m = 0.5 mm`。本课实测最大误差为 `0.00043211 m`，没有超过边界。这是几何基线，不需要用 MI 才能评估。

## 概念二：梯度、链式法则与数值检查

### 1. 两层复合函数的手推

定义：

\[
u=3x-1, \qquad f=u^2.
\]

链式法则：

\[
\frac{df}{dx}=\frac{df}{du}\frac{du}{dx}=2u\cdot 3=6(3x-1).
\]

当 `x=2`时，`u=5`、`f=25`、`df/dx=30`。中心差分基线：

\[
g_{num}=\frac{f(x+h)-f(x-h)}{2h},\qquad h=10^{-6}.
\]

实跑得 `30.000000000640625`，与分析梯度差约 `6.41e-10`。差异非零来自浮点舍入；`h` 也不是越小越好，过小时相减会损失有效数字。

**就地参考**：[CS231n Backpropagation](https://cs231n.github.io/optimization-2/)，只看 chain rule、多路梯度累加和一张计算图，10 分钟。看完关页，重画 `x→u→f` 并标注局部导数。

### 2. 凸函数与 Jensen 不等式

如果对 `0≤λ≤1`，都有：

\[
f(\lambda x+(1-\lambda)y)\leq \lambda f(x)+(1-\lambda)f(y),
\]

则 `f` 是凸函数。随机变量形式是 Jensen：

\[
f(\mathbb E[X])\leq \mathbb E[f(X)].
\]

最小算例：`f(x)=x²`，`X` 以各 `1/2` 概率取 `-1` 和 `3`。则 `E[X]=1`，`f(E[X])=1`，但 `E[f(X)]=(1+9)/2=5`，所以 `1≤5`。凸性告诉我们平均化与先计算损失再平均不可任意交换。

### 3. 稳定 log-sum-exp

原式：

\[
\operatorname{LSE}(z)=\log\sum_i e^{z_i}.
\]

对 `z=[1000,999,998]`，直接算 `exp(1000)` 会溢出。令 `m=max_i z_i=1000`：

\[
\begin{aligned}
\log\sum_i e^{z_i}
&=\log\left(e^m\sum_i e^{z_i-m}\right)\\
&=m+\log\sum_i e^{z_i-m}.
\end{aligned}
\]

因为所有 `z_i-m≤0`，指数不再向上溢出。实跑结果：

```text
LSE([1000, 999, 998]) = 1000.4076059644444
```

二分类中，logit `a`、标签 `y∈{0,1}` 的稳定 NLL 可写为：

\[
\ell(a,y)=\log(1+e^a)-ya=\operatorname{logaddexp}(0,a)-ya.
\]

其梯度是 `sigmoid(a)-y`。这个损失是概率基线，既不是互信息估计，也不单独证明模型的判别能力、校准或不确定性。

**就地参考**：[Deep Learning Book：Numerical Computation](https://www.deeplearningbook.org/contents/numerical.html)，只看 overflow/underflow 与 softmax，10 分钟；[NumPy `logaddexp`](https://numpy.org/doc/stable/reference/generated/numpy.logaddexp.html)，只看定义、参数和第一个例子，5 分钟。看完能手写减最大值等式并说出单独报 NLL 的限制。

## 常见误区

1. **“CSV 里是数字，所以精度不会变。”** 错：文本格式由 `fmt` 决定保留位数。
2. **“数组 shape 对就能计算。”** 错：米/毫米、世界/相机坐标系可以 shape 完全相同但语义相反。
3. **“丢失值直接填 0 就行。”** 错：在本课先拒绝非有限值；真实多模态还应定义模态 `X`、标签 `Y`、缺失指示 `R`，区分训练/测试/现实缺失和 MCAR/MAR/MNAR。
4. **“`exp` 溢出就换 `float128`。”** 不是通用解法：先改用数学等价的稳定公式。
5. **“数值梯度不等于分析梯度，代码一定错。”** 不一定：先检查浮点舍入和 `h` 的尺度。
6. **“NLL 小就代表模型全面可靠。”** 错：还要分开检查任务性能、校准、鲁棒性、成本和失败案例。
