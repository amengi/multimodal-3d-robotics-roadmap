## 📚 概念一：函数是有契约的变换

> **就地参考**：[Python 函数定义](https://docs.python.org/3/tutorial/controlflow.html#defining-functions)（只看 `def`、参数、作用域、`return` 和 docstring，10 分钟；看完能把一段循环封装成可测试函数）。

函数不是“把代码缩进起来”，而是一个约定：什么输入是合法的、输出是什么、失败如何表达。例如：

```python
Point = tuple[float, float]

def point_stats(points: list[Point]) -> dict[str, object]:
    """返回二维点的数量、质心和边界框；空列表时报 ValueError。"""
    if not points:
        raise ValueError("points must not be empty")
    xs = [point[0] for point in points]
    ys = [point[1] for point in points]
    return {
        "count": len(points),
        "centroid": (sum(xs) / len(xs), sum(ys) / len(ys)),
        "bbox": ((min(xs), min(ys)), (max(xs), max(ys))),
    }
```

- 输入 `points` 的逻辑 shape 是 `(N, 2)`；`N` 是点数，无单位，坐标单位是米。
- 两列是同一 `world` 坐标系中的 `x,y`。把不同坐标系直接混在一起，即使代码能运行，几何结果也没有意义。
- 类型标注帮助人和工具理解接口，但 Python 默认不会自动阻止错误类型；运行时检查仍需自己写。
- docstring 说明“做什么、输入、输出、异常”，注释更适合说明“为什么这样实现”。
- `return` 交回值；只 `print` 的函数难以复用和测试。

质心公式为

\[
\bar{x}=\frac{1}{N}\sum_{i=1}^N x_i,\qquad
\bar{y}=\frac{1}{N}\sum_{i=1}^N y_i.
\]

若四点为 `(0,0),(2,0),(2,2),(0,2)` 米，则 `N=4`，质心为 `(1,1)` 米。除以零说明空输入没有被拒绝；这不是应由调用者猜测的行为。

常见错误：可变默认参数 `def f(items=[])` 会在多次调用间共享列表；今天没有需要可变默认值，直接避免。函数修改传入列表也会制造隐式副作用，优先返回新结果。

if __name__ == "__main__":

## 🚨 概念三：异常是失败接口，不是装饰

> **就地参考**：[Python Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html)（只看 syntax errors vs exceptions、handling、raising、exception chaining，12 分钟；看完能给预期输入错误补充上下文且保留根因）。

语法错误使程序无法开始；异常是在运行过程中出现的对象。今天按三层处理：

1. **底层验证函数**发现约定被破坏，`raise PointDataError(...)`。
2. **文件读取函数**捕获预期的 `OSError` 或数字转换 `ValueError`，补充文件名/行号，并用 `raise ... from exc` 保留根因。
3. **命令行入口**捕获 `PointDataError`，打印给人看的消息并返回非零退出码；未知错误继续暴露，便于修复。

最小完整例子：

```python
class PointDataError(ValueError):
    """二维点数据违反输入契约。"""

def parse_coordinate(text: str, line_number: int) -> float:
    try:
        value = float(text)
    except ValueError as exc:
        raise PointDataError(f"line {line_number}: not a number") from exc
    if not math.isfinite(value):
        raise PointDataError(f"line {line_number}: must be finite")
    return value
```

不要写：

```python
try:
    run_everything()
except:
    pass
```

它会吞掉拼写错误、内存错误甚至退出信号，让“程序没报错”变成假成功。异常处理的验收指标不是“没有红字”，而是：合法输入成功；非法输入失败；错误类型和消息能定位问题；未知错误不被伪装。

## ∂ 概念四：张量、计算图与自动微分

> **就地参考**：[PyTorch Tensors](https://docs.pytorch.org/tutorials/beginner/basics/tensorqs_tutorial.html)（只看初始化、attributes、matrix multiplication，10 分钟；能预测每步 shape）；[PyTorch Autograd](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)（只看 `requires_grad`、graph、`backward` 和禁用梯度，12 分钟；能验证手算并说明梯度累积）。

张量是带 shape、dtype 和 device 的多维数组。自动微分记录由张量运算构成的计算图，然后用链式法则从标量输出向输入反传局部导数。

对

\[
y=x^2+3x,
\qquad \frac{dy}{dx}=2x+3.
\]

在 `x=2` 时，`y=4+6=10`，`dy/dx=4+3=7`。代码：

```python
import torch

x = torch.tensor(2.0, dtype=torch.float64, requires_grad=True)
y = x**2 + 3*x
y.backward()
print(y.item(), x.grad.item())  # 10.0 7.0
```

- `x`、`y` 都是 shape `()` 的标量张量，无量纲。
- `requires_grad=True` 表示需要追踪关于 `x` 的运算。
- `backward()` 从标量 `y` 开始反传，把结果累积进 `x.grad`。
- 再调用一次 `backward()` 会继续累积；训练循环通常先清空参数梯度。
- `.detach()` 返回与计算图分离的视图；`torch.no_grad()` 用于不需要梯度的推理。它们不等同于删除数据。

有限差分普通基线：

\[
f'(x)\approx\frac{f(x+h)-f(x-h)}{2h}.
\]

它便于验算，但 `h` 太大有截断误差，太小有浮点抵消误差。自动微分不是用微小扰动近似，二者在光滑函数上应接近。

## 🔀 实践二：双模态线性融合梯度

> **就地参考**：[CMU 11-777 Lecture 1–2 范围](https://cmu-multicomp-lab.github.io/mmml-course/fall2022/schedule/)（只看 introduction 与 multimodal representations 的标题/讲义入口，8 分钟；能把“两个模态”描述为两种数据来源）；[PyTorch 矩阵乘法](https://docs.pytorch.org/tutorials/beginner/basics/tensorqs_tutorial.html#operations-on-tensors)（只看 `@`/`matmul`，5 分钟；能手推输出 shape）。

设三条样本、两种模态，每个模态先被压成一个已标准化的无量纲特征：

\[
X=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad
w=\begin{bmatrix}0.5\\0.5\end{bmatrix},\quad
t=\begin{bmatrix}1\\0\\1\end{bmatrix}.
\]

- `X` shape `(B=3, M=2)`：行是样本，列是模态。
- `w` shape `(M=2,)`：融合权重，不是“信息量”或因果贡献。
- `p=Xw` shape `(B=3,)`，得到 `[0.5,0.5,1.0]`。
- 均方误差 `L=(1/B)Σ(pᵢ-tᵢ)²` 是无量纲标量，手算为 `(0.25+0.25+0)/3=1/6≈0.166667`。
- `∂L/∂w=(2/B)Xᵀ(p-t)`，shape `(M=2,)`，本例为 `[-1/3, +1/3]`。

### 报错处理与失败案例

| 失败 | 观察信号 | 定位顺序 | 修复后验收 |
|---|---|---|---|
| 导入失败 | `ModuleNotFoundError: materials` | `pwd` → 虚拟环境 → 是否用 `python -m` | 从根目录导入成功 |
