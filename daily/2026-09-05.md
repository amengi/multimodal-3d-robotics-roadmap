### 2.1 终端、Shell、命令和文件系统不是同一个东西（5 分钟）

> **概念参考**：[Apple Terminal User Guide：Get started](https://support.apple.com/guide/terminal/get-started-pht23b129fed/mac)（只看窗口、提示符和执行命令的说明，3 分钟，看完能指出“终端应用”和“shell”不是同一层） · [Bash Manual：What is a shell?](https://www.gnu.org/software/bash/manual/html_node/What-is-a-shell_003f.html)（只读定义段，2 分钟，看完能说出 shell 如何接收命令并启动程序）。

- **终端（terminal）**：显示文字、接收键盘输入的应用窗口。
- **shell**：读取你输入的命令、展开路径或变量、启动程序的命令解释器。macOS 默认常见的是 `zsh`。
- **命令/程序**：例如 `pwd`、`ls`、`python3`；shell 找到并运行它们。
- **文件系统**：以目录树组织文件和目录；路径是树中对象的地址。
- **进程（process）**：正在运行的程序实例，有进程编号 PID、输入、输出和退出状态。

一条命令的最小结构是：

```text
命令  选项  参数
ls   -la   materials/day002
```

空格通常分隔参数。因此路径本身含空格时要写成引号包围的一个参数，例如：

```bash
cd "/Users/meng/Documents/ChatGPT/每日基础学习"
```

### 3.2 shape、dtype、axis、索引

一个 shape 为 `(2,3,4)` 的数组可解释为：

```text
B=2 个样本 × M=3 个模态 × F=4 个数值特征
```

元素 `X[1,2,3]` 是第 2 个样本、第 3 个模态、第 4 个特征，因为索引从 0 开始。各对象的 shape：

| 表达式 | 语义 | 输出 shape |
|---|---|---:|
| `X` | 全部样本、模态、特征 | `(2,3,4)` |
| `X[0]` | 第 1 个样本的所有模态与特征 | `(3,4)` |
| `X[:,1,:]` | 所有样本的第 2 个模态 | `(2,4)` |
| `X[:,:,0]` | 所有样本、模态的第 1 个特征 | `(2,3)` |
| `X[0,1,2]` | 单个数值 | `()` 标量 |

`dtype` 表示每个元素如何存储，例如 `float64`。shape 不含单位；必须另记特征的含义与单位。本课生成的 0–9 数字是无量纲玩具特征，不能假装是米、像素或 `m/s²`。

> **边做边查**：[NumPy Indexing on ndarrays](https://numpy.org/doc/stable/user/basics.indexing.html)（只看 basic indexing 的前几个例子，5 分钟，看完能写出 `X[:,1,:]`） · [NumPy Generator](https://numpy.org/doc/stable/reference/random/generator.html)（只看 `default_rng` 和 `integers` 示例，3 分钟，看完能用固定 seed 复现实验）。

在 Python 中最小复现：

```python
import numpy as np

rng = np.random.default_rng(2)
X = rng.integers(0, 10, size=(2, 3, 4)).astype(np.float64)
print(X.shape, X.dtype)
print(X[:, 1, :].shape)
```

预期 shape 分别为 `(2, 3, 4)` 与 `(2, 4)`；具体数值由 seed `2` 固定。固定 seed 只让伪随机序列可复现，不保证不同 NumPy 版本或不同算法的所有实现永远一致，因此日志仍需记录版本。

### 3.3 按轴归约：被消掉的是哪个维度

“沿 `axis=k` 求均值”表示遍历并消去第 `k` 个轴；默认 `keepdims=False`，所以该轴从 shape 中消失：

\[
\bar X^{(F)}_{b,m}=\frac{1}{F}\sum_{f=1}^{F}X_{b,m,f}\quad\Rightarrow\quad(B,M),
\]

\[
\bar X^{(M)}_{b,f}=\frac{1}{M}\sum_{m=1}^{M}X_{b,m,f}\quad\Rightarrow\quad(B,F),
\]

\[
\bar X^{(B,M)}_{f}=\frac{1}{BM}\sum_{b=1}^{B}\sum_{m=1}^{M}X_{b,m,f}\quad\Rightarrow\quad(F,).
\]

对 `(2,3,4)`：

```python
X.mean(axis=2).shape       # (2, 3)：每个样本、每个模态，平均 4 个特征
X.mean(axis=1).shape       # (2, 4)：每个样本，平均 3 个模态
X.mean(axis=(0, 1)).shape  # (4,)：跨样本和模态，留下特征轴
```

> **就地参考**：[NumPy `mean`](https://numpy.org/doc/stable/reference/generated/numpy.mean.html)（只看 `axis`、`keepdims` 和返回 shape，4 分钟，看完能在运行前预测三条输出）。注意：不同模态的特征若单位或语义不同，直接沿模态轴平均通常没有意义；今天为了练 shape 才使用统一的玩具特征。

### 3.4 广播：不复制地对齐 shape

要对每个特征减去全数据均值，可保留被归约的轴：

```python
feature_mean = X.mean(axis=(0, 1), keepdims=True)  # (1, 1, 4)
X_centered = X - feature_mean                       # (2, 3, 4)
```

广播从最右侧比较 shape。两个维度相等，或其中一个为 `1`，才可兼容：

```text
X             (2, 3, 4)
feature_mean  (1, 1, 4)
结果          (2, 3, 4)
```

失败例：`(2,3,4) - (3,)` 从右侧比较时 `4` 与 `3` 都不为 `1`，所以报错。广播成功也不代表语义正确，例如误把长度 3 的模态偏置写成 `(3,)`，它会先尝试匹配最右的特征轴；正确形状应明确写成 `(1,3,1)`。

> **就地参考**：[NumPy Broadcasting](https://numpy.org/doc/stable/user/basics.broadcasting.html)（必读 General broadcasting rules 与一个二维例子，6 分钟，看完能手工判断 `(2,3,4)` 与 `(1,1,4)` 是否兼容）。

### 3.5 矩阵乘法：只替换最后一个特征轴

若输入 `X` 为 `(B,M,F)`，权重 `W` 为 `(F,O)`：

\[
Z_{b,m,o}=\sum_{f=1}^{F}X_{b,m,f}W_{f,o},
\qquad Z\in\mathbb{R}^{B\times M\times O}.
\]

今天 `B=2, M=3, F=4, O=2`，所以：

```python
W = np.ones((4, 2))
Z = X @ W
print(Z.shape)  # (2, 3, 2)
```

`@` 是矩阵乘法，不是逐元素 `*`。若 `W` 错写为 `(5,2)`，收缩维度 `4` 与 `5` 不匹配，必须修正接口，不能随意 reshape 数据掩盖错误。

> **就地参考**：[NumPy `matmul`](https://numpy.org/doc/stable/reference/generated/numpy.matmul.html)（只看参数 shape 与第一个高维示例，5 分钟，看完能解释为何 `(2,3,4) @ (4,2) -> (2,3,2)`）。

### 问题 2

执行 `cp a.txt b.txt` 与 `mv a.txt b.txt` 后，源路径 `a.txt` 的状态有什么区别？

<details><summary>参考答案与解析</summary>

`cp` 创建副本，成功后 `a.txt` 与 `b.txt` 都存在；`mv` 移动或重命名，成功后内容位于 `b.txt`，旧路径 `a.txt` 不再存在。

</details>

### 问题 3

`PATH`、`python3` 和“正在运行的 Python”分别属于什么？

<details><summary>参考答案与解析</summary>

`PATH` 是环境变量，其文本值列出 shell 搜索可执行程序的目录；`python3` 是命令名，对应某个解释器程序；程序被启动后产生一个 Python 进程。`command -v python3` 可查看将使用的程序路径。

</details>

### 问题 4

对 `X.shape == (2,3,4)`，`X[:,1,:]` 和 `X.mean(axis=1)` 的 shape 分别是什么？二者语义有何不同？

<details><summary>参考答案与解析</summary>

两者 shape 都是 `(2,4)`。前者选择第 2 个模态，保留它的真实数值；后者平均所有 3 个模态。shape 相同不代表语义相同。

</details>

### 问题 5

`(2,3,4)` 与 `(1,1,4)` 能否广播？`(2,3,4)` 与 `(3,)` 呢？

<details><summary>参考答案与解析</summary>

第一对可以：从右向左为 `4=4`、`3` 对 `1`、`2` 对 `1`。第二对不可以：最右维 `4` 与 `3` 不相等且都不是 `1`。

</details>

### 问题 6

`X.shape=(2,3,4)`、`W.shape=(4,5)` 时，`X @ W` 的 shape 是什么？哪个维度被求和消去？

<details><summary>参考答案与解析</summary>

输出 shape 是 `(2,3,5)`。输入最后的特征维 `F=4` 与权重第一维 `4` 配对并求和，权重最后的输出维 `O=5` 替换它。

</details>
