## 🧭 概念一：先写数据契约，再写模型

**就地参考**：[PyTorch Tensor 教程](https://docs.pytorch.org/tutorials/beginner/basics/tensorqs_tutorial.html)，只看 shape、dtype、indexing 和 NumPy bridge，8 分钟；看完能对每次索引写出输出 shape。

今天把输入写成

\[
X\in\mathbb{R}^{B\times M\times F},\qquad
Y\in\{0,1\}^{B\times 1},
\]

其中：

- `B` 是一批样本数；训练 `B=360`，验证 `B=120`。
- `M=2` 是模态/传感器轴，索引 0 为 A，1 为 B。
- `F=2` 是每个模态的特征轴。
- 数值全是无量纲合成特征，没有米、秒或像素等物理单位，也没有世界/机体/相机坐标系。
- “配对”意味着 `X[i,0,:]`、`X[i,1,:]` 和 `Y[i]` 属于同一个样本 `i`。

最小例子：若 `X.shape==(2,2,2)`，则 `X[0]` 是第 0 个样本的两个模态，shape `(2,2)`；`X[:,0,:]` 是整批的 A，shape `(2,2)`；`X.reshape(2,4)` 是每个样本内拼接，不改变样本顺序。危险写法是先 `transpose` 了样本轴，再无意识 `reshape`，这可能让 A/B 与 `Y` 错配。

## 📏 概念二：广播是 shape 规则，不是“它自己懂了”

**就地参考**：[NumPy Broadcasting](https://numpy.org/doc/stable/user/basics.broadcasting.html)，只看 general rules，8 分钟；看完能手算 `(360,2,2)-(1,2,2)` 为何合法。

对每个模态/特征单独标准化：

\[
\mu_{m,f}=\frac{1}{B_{tr}}\sum_{i\in tr}X_{i,m,f},\qquad
\sigma_{m,f}=\sqrt{\frac{1}{B_{tr}}\sum_{i\in tr}(X_{i,m,f}-\mu_{m,f})^2},
\]

\[
Z_{i,m,f}=\frac{X_{i,m,f}-\mu_{m,f}}{\sigma_{m,f}}.
\]

`X_train.shape=(360,2,2)`，`mu.shape=sigma.shape=(1,2,2)`。NumPy 从右向左对齐后，`2=2`、`2=2`、`1` 可扩展为 `360`，所以结果仍为 `(360,2,2)`。标准差为 0 时分母无效，必须拒绝退化特征，不是盲目加一个很小的数隐藏问题。

关键顺序是“先切分，再用训练集拟合 `mu/sigma`，最后用同一参数变换验证集”。若先用全部 480 个样本求统计量，验证分布已经参与了预处理，它就不再是完全留出的检查。

## 🧠 概念三：训练循环是有顺序的状态变化

**就地参考**：[PyTorch Optimization Tutorial](https://docs.pytorch.org/tutorials/beginner/basics/optimization_tutorial.html)，只看 loss function、optimizer 和 full implementation，12 分钟；看完能闭卷写训练与验证循环。

单模态基线只读 A：`(B,2,2) → X[:,0,:]:(B,2) → Linear(2,1) → logits:(B,1)`。融合 MLP 读 A+B：`(B,2,2) → reshape(B,4) → Linear(4,12) → Tanh → Linear(12,1)`。

二分类的 logit 为 `z`，概率映射为

\[
p=\sigma(z)=\frac{1}{1+e^{-z}}.
\]

`BCEWithLogitsLoss` 直接接收 `z`，数值稳定地组合 sigmoid 与 BCE。不要先手动 sigmoid 再传入这个 loss。每轮：

```python
model.train()
logits = model(train_x)          # forward
loss = loss_fn(logits, train_y)  # scalar objective
optimizer.zero_grad(set_to_none=True)
loss.backward()                  # compute gradients
optimizer.step()                 # update parameters
```

验证不学习参数：

```python
model.eval()
with torch.no_grad():
    validation_logits = model(validation_x)
```

`eval()` 切换 dropout/batch normalization 等层的行为，`no_grad()` 阻止构建梯度图；两者不是同一件事。今日模型没有 dropout/BN，但仍要建立正确接口习惯。

## 📊 概念四：判别、概率质量与校准不是同一个问题

**就地参考**：[PyTorch `BCEWithLogitsLoss`](https://docs.pytorch.org/docs/stable/generated/torch.nn.BCEWithLogitsLoss.html)，只看公式、input/target shape 和数值稳定性，7 分钟；看完能用手算一个样本的 NLL。

1. **Accuracy** 只看阈值后的类别是否正确：

   \[
   \mathrm{Acc}=\frac{1}{B}\sum_i \mathbf{1}[\mathbf{1}(p_i\ge0.5)=y_i].
   \]

2. **NLL/BCE** 惩罚给真实类低概率的预测，本页用单位 `nats/example`：

   \[
   \mathrm{NLL}=-\frac{1}{B}\sum_i[y_i\ln p_i+(1-y_i)\ln(1-p_i)].
   \]

3. **Brier score** 是概率与 `0/1` 标签的均方误差，无量纲：

   \[
   \mathrm{Brier}=\frac{1}{B}\sum_i(p_i-y_i)^2.
   \]

手算：对 `y=1`，模型甲给 `p=0.51`，乙给 `p=0.99`，两者 accuracy 都是 1；甲的 NLL 约 `-ln(0.51)=0.673`、Brier 约 `0.2401`，乙的 NLL 约 `0.010`、Brier 约 `0.0001`。反过来，若 `y=0` 却给 `p=0.99`，NLL 会非常大，因为它惩罚“非常自信但错了”。

NLL/Brier 比 accuracy 更关注概率数值，但仅报一个整体 NLL/Brier 不能宣称模型已校准。真正的校准审计还要看可靠性图、分箱和分组结果；若拟合 temperature 或阈值，只能用独立验证集，不能在最终测试集调整。

## 🧩 概念五：多模态价值要用基线和故障验证

**就地参考**：[CMU Multimodal Machine Learning 课程表](https://cmu-multicomp-lab.github.io/mmml-course/fall2022/schedule/)，只打开 Lecture 1 Introduction 的 modality 与 taxonomy 页，8 分钟；看完能为两种真实模态写出采集对象和配对键。

“两列数”并不自动等于多模态。今天为教学目的把两组特征定义为合成传感器 A/B，它们共同描述同一样本，并由样本索引配对。真实任务还必须写明：采集对象、时间窗、单位、坐标系、同步规则、采样率和缺失处理。

今天使用四组对照：

| 条件 | 看到的输入 | 用途 |
|---|---|---|
| 多数类 | 仅训练集标签比例 | 最低概率基线 |
| 稳定单模态 | `X[:,0,:]` | 说明没有 B 时还能做什么 |
| 配对 A+B 融合 | `X.reshape(B,4)` | 检查正确配对下是否有增益 |
| 打乱 B | A 不变，B 的边际值集不变，但样本对应被破坏 | 模拟同步/匹配错误 |

打乱后性能下降，只说明这个已训练模型依赖正确配对的 B。它不说明 B 因果上决定 `Y`，也不是 `I(B;Y)` 的数值。今天用监督任务指标、概率分数和失败对照已经足够，无需强行加 MI 估计器。

## 🚨 常见错误、信号与最小修复

| 信号 | 可能根因 | 最小修复 |
|---|---|---|
| `No module named materials` | 不在项目根目录，或直接以错路径运行 | `pwd`，回到根目录后用 `python -m materials.day007...` |
| `features must ... (B, 2, 2)` | 过早 flatten，或把样本轴放错 | 在数据边界打印 shape，只在融合模型内 `reshape(B,4)` |
| 标签 `(B,)` 却与 logit `(B,1)` 计算 | 少了单列轴，可能引起报错或危险广播 | 进入 loss 前断言 `y.shape==(B,1)` |
| 训练集均值不近 0 | `axis` 错，或应用了不同参数 | 用 `mean(axis=0, keepdims=True)`，检查结果 `(1,2,2)` |
| loss 不降/出现 `nan` | 学习率过大、输入非有限、忘了 `zero_grad` | 先检查 `isfinite`，再逐一核对五步顺序 |
| 每次数据/结果不同 | 不同 RNG 未固定，或在初始化后才设 seed | 在数据与模型初始化前同时固定 Python/NumPy/PyTorch seed |
| 打乱 B 后没有变化 | 只打乱了特征顺序，或模型未使用 B | 用样本级 permutation，断言 A 完全不变且 B 配对改变 |
| accuracy 高但 NLL 很差 | 大部分分类对，但少数错误极度自信 | 保留两类指标，检查错误样本概率，不只看 accuracy |
| 测试全过却无法解释 | 只复制了参考实现 | 关闭文件后重写接口，为每个断言写一句被阻止的错误 |
