## 概念一：点云先写数据契约，再谈几何

今天的源点云：

```text
P_source: shape=(N,3), dtype=float64, unit=m,
frame=cube_local, row=[x,y,z], pairing_key=point_index, finite=True
```

每行是一个三维点，不是三个样本。`axis=0` 跨点聚合，保留 x/y/z 三个坐标；`axis=1` 在每个点内部聚合。

立方体边长 `s=2 m`、中心在原点。代码在六个表面采样并用 `np.unique` 去掉棱和角的重复点，得到 296 个点。重复点不一定使图错误，却会给棱和角更大的统计权重，从而影响质心、拟合和采样密度解释。

质心是：

\[
\bar p=\frac{1}{N}\sum_{i=1}^{N}p_i\in\mathbb{R}^3,\qquad [\bar p]=\mathrm m.
\]

**就地参考**：[NumPy `mean`](https://numpy.org/doc/stable/reference/generated/numpy.mean.html)，只看 `axis=0/1` 例子，5 分钟；看完在纸上写出 `(296,3).mean(axis=0)` 与 `axis=1` 的 shape。

## 概念二：行向量刚体变换、质心与 RMSE

本课采用主动右手旋转，点按行存放：

\[
P_{world}=P_{local}R^\top+\mathbf{1}t^\top+E,
\]

其中 `P_local:(N,3)`、`R:(3,3)`、`t:(3,)`、`E:(N,3)`；坐标单位都是 m，旋转角度只用于构造 `R`，矩阵本身无量纲。绕 `+z` 旋转 `θ=30°`：

\[
R_z(\theta)=
\begin{bmatrix}
\cos\theta&-\sin\theta&0\\
\sin\theta&\cos\theta&0\\
0&0&1
\end{bmatrix}.
\]

合法旋转应满足 `RR^T=I` 且 `det(R)=+1`；`det=-1` 是包含镜像的反射，不是 proper rotation。

对所有点取均值：

\[
\bar p_{world}=\bar p_{local}R^\top+t+\bar e.
\]

立方体关于原点对称，`bar(p_local)=0`；零均值噪声的有限样本均值 `bar(e)` 接近但不必等于 0，所以估计质心位移应接近平移 `t=[1.5,-0.5,0.8] m`。

已知无噪声目标点 `q_i` 时，配对 RMSE：

\[
\mathrm{RMSE}=\sqrt{\frac1N\sum_i\lVert \hat q_i-q_i\rVert_2^2}\quad[\mathrm m].
\]

三坐标独立噪声标准差都是 `σ=0.01 m` 时，理论均方距离为 `3σ²`，大样本 RMSE 约为 `sqrt(3)σ≈0.01732 m`。本次实测 `0.017024 m`，这是随机样本值，不是必须逐位复现的常数。

**就地参考**：[NumPy absolute basics](https://numpy.org/doc/stable/user/absolute_beginners) 只看矩阵运算、广播与聚合，8 分钟；看完手算 `[1,0,0]` 绕 z 轴 90° 后再平移 `[1,2,3]` 的结果 `[1,3,3]`。

## 概念三：AABB 是坐标轴相关的摘要

轴对齐包围盒（axis-aligned bounding box, AABB）：

\[
b_{min,j}=\min_i p_{ij},\quad b_{max,j}=\max_i p_{ij},\quad
d_j=b_{max,j}-b_{min,j}.
\]

`min/max/extent:(3,)`，单位 m。AABB 的边永远与当前坐标轴平行，所以物体只旋转、不变形，AABB 也可能改变。

边长 `s` 的正方形绕 z 旋转 `θ` 后，x/y 方向无噪声 AABB 理论跨度都是：

\[
d_x=d_y=s(|\cos\theta|+|\sin\theta|).
\]

`s=2 m, θ=30°` 时约 `2.732 m`；实测有噪声后为约 `[2.778,2.761,2.040] m`。这不代表立方体膨胀，只代表坐标轴相关包围盒加上极值对噪声敏感。要估计物理尺寸，可比较已知姿态下的局部坐标范围，或使用有向包围盒；今天不把 AABB 当作形变证据。

**就地参考**：[Matplotlib mplot3d](https://matplotlib.org/stable/users/explain/toolkits/mplot3d.html)，只看创建 3D Axes 和 scatter，6 分钟；看完检查图的三轴都标 m，并解释图为何不能替代数值范围。

## 概念四：独立、协方差与 Pearson 不是同义词

随机变量独立要求联合分布处处因子化：

\[
p_{X,Y}(x,y)=p_X(x)p_Y(y).
\]

离散事件版本：对所有事件 `A,B`，`P(A∩B)=P(A)P(B)`。只要找到一个反例，就能否定独立。

协方差与 Pearson 相关：

\[
\mathrm{Cov}(X,Y)=E[(X-E[X])(Y-E[Y])],
\qquad
\rho_{XY}=\frac{\mathrm{Cov}(X,Y)}{\sigma_X\sigma_Y}.
\]

独立且二阶矩存在时，`E[XY]=E[X]E[Y]`，所以协方差为 0；但零协方差只排除了线性共同变化，不排除非线性依赖。

令 `X~N(0,1)`、`Y=X²+ε`，且 `ε` 与 `X` 独立、均值为 0。标准正态关于 0 对称，奇数阶矩 `E[X³]=0`：

\[
\mathrm{Cov}(X,Y)=E[X(X^2+\epsilon)]-E[X]E[Y]
=E[X^3]+E[X\epsilon]=0.
\]

但知道 `|X|` 几乎决定 `X²` 的大小，所以 `X,Y` 明显不独立。本次样本 `r(X,Y)=0.0050`，而 `r(|X|,Y)=0.9216`。

**就地参考**：[MIT 18.05 Class 7](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/pages/classes-reading-and-in-class-materials/) 只读 Class 7a/7b 的 independence、covariance、correlation，12 分钟；看完关闭网页写出“独立 ⇒ 零协方差；零协方差 ⇏ 独立”。

## 概念五：用事件反例和任务基线补足相关系数

定义事件：

```text
A = {|X| > 1}
B = {Y > 1}
```

若独立，应满足 `P(A∩B)=P(A)P(B)`。本次 1200 个样本：

```text
P(A∩B)=0.2967
P(A)P(B)=0.1059
absolute gap=0.1908
```

有限样本概率不会精确等于总体概率，但如此大的差距与散点的 U 形共同构成可审计的反证。

再比较三个普通监督基线，训练集占前 75%，测试集占后 25%：

- 常数：`ŷ=β0`；测试 RMSE `1.461817`。
- 线性：`ŷ=β0+β1X`；测试 RMSE `1.463840`。
- 二次：`ŷ=β0+β1X+β2X²`；测试 RMSE `0.275602`。

用 `np.linalg.lstsq(A,y)` 最小化 `||y-Aβ||₂`。二次模型在未参与拟合的测试样本上显著更好，说明 `X` 对 `Y` 有非线性预测价值。它仍不能证明 `X` 导致 `Y`；这里的因果方向只是合成数据生成规则已知。

**就地参考**：[`numpy.linalg.lstsq`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)，只看目标函数、`A:(M,N)`、`b:(M,)` 和直线示例，8 分钟；看完写出二次 design matrix 的一行为 `[1,x_i,x_i²]`。

### 迁移题

机器人系统有相机点云 `X_cam:(N,3)`、触觉特征 `X_touch:(d,)`、抓取成功标签 `Y` 和缺失指示 `R_cam,R_touch`。请写出：

1. 两个模态的单位、frame、时间戳/样本 ID、训练/测试缺失分别怎样记录；
2. 一个稳定单模态基线、一个简单融合基线、一个错配失败对照；
3. 应报告的任务性能、校准、成本和按模态子集样本量；
4. 为什么低相关、高相关或逼真补全都不能证明因果、可靠或隐私安全。

**就地参考**：先独立作答；卡住后看 [`INFORMATION_THEORY_SCOPE.md`](../INFORMATION_THEORY_SCOPE.md) 的“非完备多模态最低实验协议”和“使用边界”，10 分钟。

<details>
<summary>折叠答案（完成后再展开）</summary>

1. `axis=0` 跨 N 个点分别平均 x/y/z，输出 `(3,)`；`axis=1` 会给每个点三个坐标的平均，输出 `(N,)`，没有常用几何含义。
2. 列向量公式是 `Rp+t`；把点存为行后需转置为 `p@R.T+t`。手算结果 `[1,3,3]`。
3. 正交只保证保长度/角度；`det=-1` 改变手性并含反射，不能由连续纯旋转得到。
4. AABB 的边锁定当前坐标轴。旋转后的角点在 x/y 轴投影范围变大，物体自身边长没有变化。
5. 独立且二阶矩存在 ⇒ 协方差为 0 ⇒ Pearson 为 0（标准差非零）。反向一般都不成立。
6. 对称分布令 `E[X³]=0`，正负 X 在线性乘积中抵消；但 Y 的大小随 `|X|` 明显变化，所以条件分布不同。
7. 独立要求所有事件都满足因子化，找到一个不满足的事件即可反驳。有限样本 gap 接近 0 可能是抽样波动、事件选择不敏感或功效不足，不能证明所有事件都因子化。
8. 说明加入 `X²` 后在同分布测试集上预测更好，支持非线性预测关系；不证明因果、部署泛化，也不等于完整刻画联合分布。

**动手题**：无噪声时源质心为 0，目标质心始终等于平移；已知变换生成的 clean target 与自身比较 RMSE 为 0。x/y AABB 从 2 m 随角度增大，45° 时约 `2√2 m`；z 始终 2 m。

**迁移题**：用 timestamp/sample ID 对齐，记录单位、坐标系、采样窗口和 `R`；按训练、测试、现实采集流程区分缺失，讨论 MCAR/MAR/MNAR 只能作为有证据的假设。比较相机单模态、触觉单模态、零/均值填充+mask 或集合式融合，并做时间错移/样本打乱；按模态子集报告 n、任务指标、NLL/Brier/ECE、采集成本与失败案例。相关不是因果，补全逼真不是任务可靠，匿名化/低 MI 也不是差分隐私保证。
