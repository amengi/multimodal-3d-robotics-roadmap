## 🧭 概念一：先看问题结构，再选 API

**就地参考**：[NumPy Linear Algebra 总览](https://numpy.org/doc/stable/reference/routines.linalg.html)，只看 matrix/vector products、decompositions、norms 和 solving equations，6 分钟；看完能用下表路由问题。

| 问题 | 输入 shape | 首选 API | 输出 | 常见错误 |
|---|---|---|---|---|
| 矩阵—向量/矩阵乘法 | `(m,n)@(n,)` 或 `(m,n)@(n,k)` | `@` / `np.matmul` | `(m,)` 或 `(m,k)` | 内维不等；把元素乘 `*` 当矩阵乘 |
| 向量内积 | `(n,)·(n,)` | `np.dot` 或 `@` | 标量 | 没写清一维数组不区分行/列 |
| 长度/误差大小 | `(n,)` 或指定 axis | `np.linalg.norm` | 标量或降维数组 | 忘了 axis，把整批压成一个数 |
| 方形方程 `Ax=b` | `A:(n,n), b:(n,)` | `np.linalg.solve` | `x:(n,)` | `A` 奇异；显式 `inv(A)@b` |
| 超定/欠定最小二乘 | `A:(m,n), b:(m,)` | `np.linalg.lstsq` | 解、残差、秩、奇异值 | 忽略 rank；默认残差一定非空 |
| 通用分解/主方向 | `X:(N,F)` | `np.linalg.svd` | `U,s,Vt` | 未中心化；把 `Vt` 当 `V` |
| 对称矩阵特征分解 | `C:(F,F), C=C.T` | `np.linalg.eigh` | 升序特征值/列特征向量 | 忘记倒序；逐元素比向量符号 |

对

\[
A=\begin{bmatrix}3&1\\1&2\end{bmatrix},\quad
b=\begin{bmatrix}9\\8\end{bmatrix},
\]

手算得 `x=[2,3]`。程序验收不是“打印看起来对”，而是检查 `np.linalg.norm(A @ x - b)` 接近 0。

### 为什么 `solve(A,b)` 优先于 `inv(A)@b`

**就地参考**：[`numpy.linalg.solve`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)，只看非奇异方形前提和 `LinAlgError`，5 分钟；看完能为奇异矩阵写失败测试。

`solve` 直接利用分解求解系统，无需构造完整逆矩阵；通常工作量和数值误差都更合理。但 `solve` 不能修复奇异或极度病态的问题；必须检查建模是否可识别、单位尺度和条件数，而不是换一个 API 就宣称稳定。

## 📏 概念二：最小二乘拟合是“找残差最小的参数”

**就地参考**：[`numpy.linalg.lstsq`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)，只看问题定义、`rcond` 与返回的 solution/residuals/rank/s，8 分钟；看完能说明哪些情况下 residuals 可为空。

对 `N` 个以米为单位的观测 `(x_i,y_i)`，拟合

\[
y_i\approx a x_i+b.
\]

写成

\[
\underbrace{\begin{bmatrix}
x_1&1\\x_2&1\\\vdots&\vdots\\x_N&1
\end{bmatrix}}_{A:(N,2)}
\underbrace{\begin{bmatrix}a\\b\end{bmatrix}}_{\theta:(2,)}
\approx
\underbrace{\begin{bmatrix}y_1\\y_2\\\vdots\\y_N\end{bmatrix}}_{y:(N,)}.
\]

`a` 的单位是 `m/m`，即无量纲；`b`、`y_hat` 和残差 `r=y-y_hat` 是米。最小二乘求

\[
\theta^*=\arg\min_\theta \lVert A\theta-y\rVert_2^2.
\]

在满列秩且无权情形，最优残差与设计矩阵列空间正交：`A.T @ r ≈ 0`。不要自己写正规方程的显式逆 `(A.T@A)^-1`：它可能放大条件数问题，也会丢失 `lstsq` 提供的 rank/奇异值审计。

最小手算：`x=[0,1,2] m`、`y=[1,3,5] m`，则 `A=[[0,1],[1,1],[2,1]]`，精确解是 `a=2,b=1 m`，残差全 0。真实噪声数据不期望残差为 0；要画残差对 `x` 的图，检查弯曲趋势、异方差和异常点。

RMSE 为

\[
\mathrm{RMSE}=\sqrt{\frac1N\sum_i(y_i-\hat y_i)^2},
\]

单位与 `y` 相同，即米。普通基线是对每个样本都预测训练数据的 `mean(y)`；拟合必须在同一样本和同一 RMSE 定义下与它比。

## 🧠 概念三：SVD 是 PCA 的可审计实现路径

**就地参考**：[`numpy.linalg.svd`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html) 只看 reduced SVD 与 shapes，6 分钟；[scikit-learn PCA 说明](https://scikit-learn.org/stable/modules/decomposition.html#pca) 只看中心化、SVD 投影和 explained variance，6 分钟；看完能从原始 `X` 得到 scores 和重建。

对无量纲合成特征 `X:(N,F)`：

1. 先只沿样本轴中心化：`mu=X.mean(axis=0):(F,)`，`X_c=X-mu:(N,F)`。
2. 令 `K=min(N,F)`，reduced SVD 为

   \[
   X_c=U\,\mathrm{diag}(s)\,V^T,
   \]

   其中 `U:(N,K)`、`s:(K,)`、`Vt:(K,F)`。
3. 前 `k` 个主方向 `components=Vt[:k]:(k,F)`。
4. 低维坐标 `scores=X_c@components.T:(N,k)`。
5. 重建 `X_hat=scores@components+mu:(N,F)`。

第 `j` 个方向的样本方差是

\[
\lambda_j=\frac{s_j^2}{N-1},\qquad
\mathrm{EVR}_j=\frac{\lambda_j}{\sum_\ell\lambda_\ell}.
\]

EVR 是样本方差比例，不是 bit/nat，也不是 `I(Z;Y)`。如果任务相关信号恰好是低方差方向，PCA 可能把它丢掉。因此今日同时报告重建 RMSE 和失败边界，不宣称任务性能。

## 🧪 概念四：用 `eigh` 交叉验证，不逐元素比方向

**就地参考**：[`numpy.linalg.eigh`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eigh.html)，只看对称/Hermitian 假设、特征值升序和特征向量按列返回，5 分钟；看完能正确排序并比较 SVD 的 `Vt[0]`。

样本协方差为

\[
C=\frac{X_c^T X_c}{N-1}\in\mathbb{R}^{F\times F},\qquad C=C^T.
\]

由于 `C` 是实对称矩阵，`eigh` 会利用这个结构，返回实特征值和正交特征向量。NumPy 按升序返回，而 PCA 通常要降序。理论上 `eigh(C)` 的特征值与 `s^2/(N-1)` 一致。

向量 `v` 和 `-v` 表示同一条轴；不应要求逐元素完全相等。比较单一主方向用 `abs(v_svd @ v_eigh) ≈ 1`；存在重复/近重复特征值时，单个向量还可在其子空间内旋转，应比子空间而不是某一根轴。

## 🚨 常见错误与报错处理

| 现象 | 根因 | 处理 |
|---|---|---|
| `matmul` 维度不匹配 | `A:(m,n)` 与右侧第一维不是 `n` | 乘法前写 shape 等式，不靠反复转置试错 |
| `LinAlgError: Singular matrix` | 方程不可唯一识别 | 检查 rank/建模；不加随意小数假装解决 |
| `lstsq` 的 residuals 为空 | 设计矩阵非满列秩，或 `m<=n` | 自行算 `r=y-A@theta` 与 `r@r`，同时报 rank |
| 斜率/截距很大但残差小 | `x` 取值范围太小或单位混乱 | 报条件、范围与单位，不只看 RMSE |
| PCA 第一主方向反号 | SVD/特征向量符号本来不唯一 | 比 `abs(dot)` 或重建，不强行改某个元素符号 |
| `eigh` 主方向取错 | 它按升序返回特征值 | 用降序 order 同时重排特征值和特征向量列 |
| PCA EVR 很高但任务失败 | 高方差不一定是任务相关信号 | 加入任务基线/监督指标；不把 EVR 写成 MI 或性能 |
| Matplotlib 无窗口报错 | 服务器无 GUI backend | 参考代码使用 `Agg`，保存 PNG 而不强制 `show()` |

<summary>折叠答案与核对要点</summary>

1. `A@x` 是 `(4,)`；`A.T@A` 是 `(3,3)`。前者内维 3 消去，后者是 `(3,4)@(4,3)`。
2. `solve` 要求方形非奇异 `A:(n,n)` 并解精确系统；`lstsq` 允许矩形 `A:(m,n)` 并最小化残差。显式逆构造不需要的整个矩阵，常更慢且数值误差更难控制。
3. `A=[[0,1],[1,1],[2,1]]`，`θ=[2,1]`，拟合值 `[1,3,5]`，残差全 0。斜率是 m/m=无量纲，截距是 m。
4. `K=min(100,3)=3`，所以 `U:(100,3)`、`s:(3,)`、`Vt:(3,3)`。一维 scores `(100,1)`，重建回 `(100,3)`。
5. `C=X_c.T@X_c/(N-1)=V diag(s²/(N-1)) V.T`，所以右奇异向量是协方差特征向量。`v` 和 `-v` 是同一主轴，因此比内积绝对值。
6. EVR=0.98 只表示样本总方差的 98% 在该主方向上。它不使用标签，不给出互信息，不证明语义保留或因果方向。
7. 设计矩阵是 `column_stack([x,ones])`，`lstsq(...,rcond=None)` 后查 rank=2；自行算 `pred=A@theta`、`r=y-pred`。常数 `x` 使两列线性相关，`nan` 必须在 LAPACK 前拒绝。
8. 先记录每列单位、范围、方差和业务意义；比较原始 PCA、有理由的标准化 PCA、各单模态以及直接丢列基线。同时报重建误差与真实任务指标，按单位/模态分层检查失败。不能因为标准化后 EVR 好看就宣称语义正确。
