## 概念二：变量、类型、函数与 `struct`

片段：

```cpp
struct Point2D {
    double x;
    double y;
};

struct PointStats {
    std::size_t count;
    Point2D centroid;
    Point2D minimum;
    Point2D maximum;
};
```

`Point2D` 把两个有共同含义的 `double` 坐标组合成一个新类型；`PointStats` 把一组统计结果组合成一个返回值。今天先把 `struct` 当作“有名字的数据记录”，类与封装留到 Day 017。

函数头：

```cpp
PointStats compute_stats(const std::vector<Point2D>& points)
```

从左到右读：函数返回一个 `PointStats`；函数名是 `compute_stats`；参数 `points` 是 `std::vector<Point2D>` 的只读引用。

函数的契约是：

```text
input : points:(N,2), double, unit=m, frame=world, N>0, finite
output: count, centroid:(2,), minimum:(2,), maximum:(2,)
failure: empty input or any NaN/Inf -> std::invalid_argument
```

## 概念三：`std::vector`、范围循环与 `const`

程序用下面的容器保存四个点：

```cpp
const std::vector<Point2D> points{
    {1.0, 2.0}, {3.0, 4.0}, {-1.0, 0.0}, {1.0, -2.0}
};
```

可以把它理解为 `N=4` 行、每行两个坐标的动态序列。`std::vector` 管理自身存储；今天不手写 `new/delete`。

```cpp
for (const Point2D& point : points) {
    sum_x += point.x;
    sum_y += point.y;
}
```

- `for (... : points)`：依次访问容器中的每个元素。
- `&`：`point` 引用原元素，不创建完整副本。
- `const`：循环体只能读取该元素，不能意外修改点。
- `const std::vector<...>&` 参数：调用函数时不复制整个容器，函数也不能通过该参数修改容器。

这里的 `const` 表达接口意图，但它不是线程安全、数学正确或输入合法的保证；因此代码仍需检查空集合和非有限值。

### 四点手算

点为 `(1,2),(3,4),(-1,0),(1,-2)`：

```text
N = 4
sum_x = 1+3-1+1 = 4       centroid_x = 4/4 = 1 m
sum_y = 2+4+0-2 = 4       centroid_y = 4/4 = 1 m
min = (-1,-2) m
max = ( 3, 4) m
```

AABB 是与 `world` 坐标轴对齐的矩形摘要；它不是点间距离，也不能单独证明物体形状。

## 概念四：自信息量的定义、底数与单位

对离散随机变量 `X` 的一个结果 `x`，若 `P(X=x)=p(x)`，自信息量定义为：

```text
h_b(x) = -log_b p(x),       0 < p(x) <= 1
```

底数决定单位：

- `b=2`：单位是 bit；
- `b=e`：单位是 nat；
- 换底只改变数值尺度：`h_e(x)=h_2(x) ln 2`。

手算：

| `p(x)` | `-log₂ p(x)` | `-ln p(x)`（约） | 直觉 |
|---:|---:|---:|---|
| `1` | `0 bit` | `0 nat` | 必然发生，没有惊讶 |
| `1/2` | `1 bit` | `0.693147 nat` | 二选一中的一个结果 |
| `1/4` | `2 bit` | `1.386294 nat` | 概率再减半，增加 1 bit |
| `1/8` | `3 bit` | `2.079442 nat` | 更罕见，信息量更大 |

因为 `0<p<=1`，所以 `log p<=0`，前面的负号使自信息非负。`p=0` 时 `-log p` 发散到无穷，程序应拒绝把它当作普通有限数；`p>1` 不是合法概率。

### 自信息不是熵

- 自信息 `h(x)`：针对已经观察到的一个结果。
- 熵 `H(X)=E[h(X)]`：观察结果之前，对随机变量平均不确定性的摘要。

今天只要求前者。高自信息不表示结果“有用”“正确”或“有因果价值”；它只是在指定概率模型下较罕见。

## 跨线整合（10 分钟）

在笔记中照抄结构、自己填内容：

```text
系统 A：二维点统计
input  : points_m:(N,2), frame=world, unit=m, N>0, finite
process: vector -> range for -> sum/min/max
output : count, centroid_m:(2,), AABB min/max_m:(2,)
failure: empty / NaN / Inf

系统 B：自信息量
input  : event x, model probability p(x), 0<p<=1, dimensionless
process: -log_b p(x)
output : scalar h_b(x), unit=bit if b=2, nat if b=e
failure: invalid p / unspecified log base / probabilities from wrong model
```

两条线的共同点不是“都用了数字”，而是都必须声明输入域、输出含义、单位和失败条件。几何坐标的单位是 m，概率无量纲，自信息的单位来自对数底数；三者不能混用。

<summary>折叠答案（完成后再展开）</summary>

1. `.cpp` 是人写的源文本；编译器检查并翻译；可执行文件由操作系统运行；标准输出是程序运行时写出的文本流。

7. 同一个对数换底：`1 bit × ln2 = 0.693147 nat`。单位不同，事件和概率没有改变。
