# 多模态 × 互信息 × 三维重建 × 机器人：24 周每日学习路线

从 **2026-09-03** 开始，共 **24 周 / 168 天**。每天 **2–4 小时**，包含学习、推导/编程、跨线整合和可量化检测。

## 怎样使用

1. 打开 [总路线](ROADMAP.md)，再进入当天所在周的每日文件；课程编号见 [资源索引](RESOURCES.md)。
2. 先做 2 小时核心；时间充足再做专项/加深模块，不用牺牲检测环节。
3. 每天提交 `notes/DayNNN.md`、`experiments/DayNNN/` 和 `progress.csv`。
4. 当日低于 4/6，次日先补；每周低于 16/20，不进入新周。

## 时间结构

- **2 小时最低配置**：10 分钟回忆 + 45 分钟学习 + 50 分钟推导/代码 + 15 分钟检测与提交。
- **3 小时标准配置**：在最低配置上增加 45 分钟专项 + 15 分钟跨线总结。
- **4 小时深入配置**：再增加 45 分钟实验/论文 + 15 分钟复现实验清理。

路线合并自两份用户提供的学习文档；原文只作为课程内容来源，本仓库的执行规则以本 README 和每日文件为准。
